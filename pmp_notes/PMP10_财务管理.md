# PMP10 财务管理（成本）

> 来源：骐迹教育第 10 讲。EVM 公式必须会算会判。

## 一、成本概念

| 概念 | 含义 | 别踩 |
|------|------|------|
| 生命周期成本 | 项目期成本视角 | 勿与「全生命周期」混用题意 |
| 全生命周期成本 | 含运营/维护等更长跨度 | 选型/采购常考 |
| 沉没成本 | 已发生不可收回 | **决策不该再被沉没成本绑架** |

## 二、过程骨架

| 过程 | 输出要点 |
|------|----------|
| 规划成本管理 | 成本管理计划（控制账户、EVM 技术等） |
| 估算成本 | 成本估算、估算依据 |
| 制定预算 | 成本基准、项目资金需求 |
| 控制成本 | EVM、预测、变更 |

## 三、估算准确度

| 类型 | 典型区间 |
|------|----------|
| 粗略量级 ROM | 约 -25% ~ +75% |
| 确定性估算 | 约 -5% ~ +10% |

## 四、成本构成四块（常考）

1. **直接成本**（人工、材料等可归属活动）  
2. **间接成本**（分摊）  
3. **应急储备**（已知风险）→ 通常进**成本基准**  
4. **管理储备**（未知风险）→ **通常不进成本基准**；动用常需变更  

另：质量成本 COQ = 预防 + 评估 + 失败（内/外）。

**口诀：已知应急进基准；未知管理在外面。**

## 五、预算与资金限制

- 成本基准是经批准的、分时段的预算（通常含应急、不含管理储备）  
- 资金限制平衡：花钱曲线对齐出资节奏  
- 历史信息审核：用类似项目校验  

## 六、挣值 EVM（必背）

| 指标 | 公式 | 判读 |
|------|------|------|
| PV | 计划值 | 计划该完成多少 |
| EV | 挣值 | 实际完成值多少 |
| AC | 实际成本 | 实际花了多少 |
| CV | EV − AC | >0 省钱；<0 超支 |
| SV | EV − PV | >0 超前；<0 落后 |
| CPI | EV / AC | >1 成本效率好 |
| SPI | EV / PV | >1 进度效率好 |
| BAC | 完工预算 | 原基准总预算 |
| ETC | 仍需成本 | 视假设 |
| EAC | 完工估算 | 见下 |
| VAC | BAC − EAC | 完工偏差 |
| TCPI | (BAC−EV)/(BAC−AC) | 剩余工作须达效率 |

### EAC 四种考法

1. **典型**（当前 CPI 持续）：`EAC = BAC / CPI`  
2. **非典型**（偏差一次性）：`EAC = AC + (BAC − EV)`  
3. **自下而上重估**：`EAC = AC + 新 ETC`  
4. **考虑 SPI×CPI**：`EAC = AC + (BAC − EV)/(SPI×CPI)`  

交叉判读：CV+ SV− → 常「人没到位，钱省了进度慢」；CV− SV+ → 可能赶工换时间。

## 七、易错对照

| 题干信号 | 选这 | 别选那 |
|----------|------|--------|
| 最大把握估算 | 自下而上 | 类比 |
| 有类似历史项目 | 类比（早期） | 硬上自下而上唯一解 |
| SPI 用到 | PV（及 EV） | 乱选 EAC/ETC |
| 偶发拨款（管理储备类） | EVM 分析时分清是否进基准 | 与 AC 混为一谈 |
| 沉没很多还要加码 | 看未来价值与风险 | 「已经花了必须做完」 |
