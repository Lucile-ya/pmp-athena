# PMP2 价值交付体系

> 来源：骐迹教育第 2 讲课件摘要。ECO「业务环境」抬高，本讲必做成题。

## 一、价值是什么

价值 = 值得的事物；可财务亦可非财务。项目通过成果创造价值，例如：

1. 满足客户/最终用户需要的新产品、服务或结果  
2. 积极的社会或环境贡献  
3. 提高效率、生产力、效果或响应能力  
4. 推动组织向期望未来状态过渡  
5. 维持既有收益  

## 二、价值交付系统（VDS）

组织持续识别机会 → 通过项目/项目集/产品/运营交付成果 → 实现收益与价值。

| 组件 | 作用 |
|------|------|
| 战略 | 方向与优先级 |
| 项目组合 | 投资组合对齐战略 |
| 项目集/项目 | 交付成果 |
| 产品/运营 | 持续产生与维持价值 |
| 度量与反馈 | 信息回流，调整组合 |

## 三、信息流

- 战略意图向下传递到组合与项目  
- 绩效、风险、变更、经验向上反馈  
- 度量指标数据库支撑过程与产品测量  

## 四、组织治理相关角色

| 角色 | 典型职责 |
|------|----------|
| PMO | 过程资产、模板、资源索引、历史经验、结构化审查 |
| 治理委员会 | 决策、优先级、重大变更/投资 |
| 审计师 | 合规与过程有效性审查 |
| 发起人 | 授权、资源、高层支持、商业论证背书 |

## 五、与项目有关的职能（记分类）

| 职能类型 | 通常谁负责 | 例子 |
|----------|------------|------|
| 监督与协调 | PM / 项目管理团队 | 整合计划与执行 |
| 引导与支持 | PM | 团队引导、变更支持 |
| 运用专业知识 | 团队 + SME | 技术贡献、供应商按合同支持 |
| 治理相关 | PMO / 治理委员会 | 标准、审批、组合决策 |

## 六、考场口诀

1. **价值 ≠ 交付物；问收益/成果优先对齐战略**  
2. **信息要上下通：战略下传，绩效上传**  
3. **治理定规矩，PM 在授权内整合交付**  
4. **PMO 给资产与支持，不替 PM 做所有决策**
