## 五大过程组

1. **启动过程组 (Initiating)**：定义新项目或新阶段，获得授权
2. **规划过程组 (Planning)**：明确范围、优化目标、制定行动方案
3. **执行过程组 (Executing)**：完成项目管理计划中确定的工作
4. **监控过程组 (Monitoring & Controlling)**：跟踪、审查和调整项目进展与绩效
5. **收尾过程组 (Closing)**：正式完成或关闭项目/阶段

## 十大知识领域

| 知识领域 | 核心关注点 |
|----------|-----------|
| 整合管理 | 统一协调各知识领域 |
| 范围管理 | 确保项目包含所有必需的工作 |
| 进度管理 | 按时完成项目 |
| 成本管理 | 在批准的预算内完成 |
| 质量管理 | 满足需求 |
| 资源管理 | 识别、获取和管理资源 |
| 沟通管理 | 信息及时恰当的传递 |
| 风险管理 | 识别、分析和应对风险 |
| 采购管理 | 从外部获取产品/服务 |
| 干系人管理 | 识别和满足干系人期望 |

## 记忆口诀

**启动-规划-执行-监控-收尾** = "启规执监收"

十大领域可以按"整范进成质，资沟风采干"来记：
- 整 = 整合
- 范 = 范围
- 进 = 进度
- 成 = 成本
- 质 = 质量
- 资 = 资源
- 沟 = 沟通
- 风 = 风险
- 采 = 采购
- 干 = 干系人

## 关键考点

1. 每个过程组都有对应的知识领域过程，49 个过程分布在 5 大过程组 × 10 大知识领域的矩阵中
2. 规划过程组包含 24 个过程（最多），收尾只有 1 个（结束项目或阶段）
3. 变更请求走整体变更控制流程：提交变更 → 评估影响 → 审批 → 更新计划 → 实施
