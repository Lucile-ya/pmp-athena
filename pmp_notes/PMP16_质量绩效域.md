# PMP16 质量绩效域

> 来源：骐迹教育第 16 讲。规划质量 / 管理质量 / 控制质量三件套。

## 一、三过程对照

| 过程 | 焦点 | 典型输出/工具 |
|------|------|----------------|
| 规划质量管理 | 标准与怎么测 | 质量管理计划、质量测量指标、COQ、标杆、成本效益 |
| 管理质量（QA） | **过程**是否有效、合规 | 审计、过程分析、亲和图、根因、质量改进 |
| 控制质量（QC） | **可交付物**是否达标 | 检查、控制图、测试、核实的可交付成果 |

**口诀：QA 管过程，QC 验成果；规划先定尺子。**

## 二、质量成本 COQ

| 类型 | 例子 |
|------|------|
| 预防 | 培训、设计评审、正确流程 |
| 评估 | 测试、检查、检验 |
| 内部失败 | 返工、废品（交付前） |
| 外部失败 | 保修、投诉、召回（交付后） |

原则：**预防优于评估**；失败成本通常最高。

## 三、规划常用工具

| 工具 | 用途 |
|------|------|
| 标杆对照 | 与最佳实践比 |
| 成本效益分析 | 质量活动值不值 |
| 质量成本 | 权衡预防/评估/失败 |
| 测试与检查规划 | 何时测、测什么 |
| 质量测量指标 | 准时率、缺陷率、可用性等可量化 |

## 四、管理质量工具

| 工具 | 用途 |
|------|------|
| 根本原因分析 | 鱼骨等，找真因 |
| 亲和图 | 归类创意/问题 |
| 直方图 | 分布形态 |
| 审计 | 多由外部/PMO；查政策符合与改进机会 |
| 问题解决 | 结构化闭环 |

审计：**独立审查质量管理活动是否有效**（管理质量）。

## 五、控制质量：控制图

| 规则 | 含义 |
|------|------|
| 1 点规则 | 一点超出控制限 → 可能失控 |
| 7 点规则 | 连续 7 点在均值同侧 → 过程可能异常 |

控制图帮助判断**过程是否失控**，不是直接「管资源」。

## 六、质量 vs 等级

- 质量：需求满足程度  
- 等级：功能档次  
- 低等级可接受；**低质量不可接受**  

## 七、易错对照

| 题干信号 | 选这 | 别选那 |
|----------|------|--------|
| 重复缺陷 | 根因 + 改过程（QA） | 只返工当前件 |
| 问过程是否失控 | 控制图 | 只加资源 |
| 戴明思想 | 持续改进 / 预防导向等 | 与质量零成本等乱配 |
| 测量指标内容 | 属性、如何验证符合 | 等同于整本质量政策全文 |
