# 2.1 项目的启动

## 制定项目章程 (4.1)

项目章程是**正式授权**项目存在并赋予项目经理动用组织资源的权力的文件。

| 属性 | 说明 |
|------|------|
| 签发人 | 发起人 (Sponsor) |
| 项目经理角色 | 参与制定，不单独签发 |
| 何时签发 | 项目启动阶段 |
| 核心内容 | 项目目的、目标、成功标准、退出标准、关键干系人、总体里程碑、总体预算、项目经理任命 |

## 商业文件

| 文件 | 说明 | 谁制定 | 项目经理能否修改 |
|------|------|--------|------------------|
| 商业论证 | 论证项目是否值得投资（成本效益分析） | 发起人/商业分析师 | 只能提建议 |
| 效益管理计划 | 如何、何时实现和衡量项目效益 | 发起人/商业分析师 | 只能提建议 |

## 识别干系人 (13.1)

识别所有可能影响或被项目影响的个人、团体或组织。

| 关键输入 | 关键工具 | 关键输出 |
|----------|----------|----------|
| 项目章程 | 干系人分析 | 干系人登记册 |
| 商业文件 | 权力/利益方格 | 变更请求 |
| 协议 | 问卷、头脑风暴 | — |

## 干系人分析

| 维度 | 说明 |
|------|------|
| 权力 (Power) | 干系人的职位/决策权级别 |
| 利益 (Interest) | 干系人对项目结果的关注程度 |
| 影响 (Influence) | 干系人对项目成果的影响能力 |
| 态度 | 支持者 / 中立者 / 反对者 |

## 启动会议 (Kick-off Meeting)

| 英文注意 | 考点 |
|----------|------|
| Kick-off Meeting | 规划完成后、执行开始前召开，传达计划、建立共识 |
| Initiating Meeting | 启动阶段结束时召开，类似章程审批会议 |
