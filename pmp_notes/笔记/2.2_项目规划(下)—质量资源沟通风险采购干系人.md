# 2.2 项目规划（下）— 质量、资源、沟通、风险、采购、干系人

## 质量管理

| 过程 | 过程组 | 核心 |
|------|--------|------|
| 8.1 规划质量管理 | 规划 | 质量测量指标、质量管理计划 |
| 8.2 管理质量 (QA) | 执行 | 过程审计、过程改进 |
| 8.3 控制质量 (QC) | 监控 | 检查可交付物、测量结果 |

### QA vs QC

| | 管理质量 (QA) | 控制质量 (QC) |
|------|-------------|-------------|
| 关注 | **过程**是否合规 | **结果**是否达标 |
| 时间 | 执行期间 | 可交付物完成后 |
| 工具 | 质量审计、过程分析 | 检查、统计抽样 |
| 负责人 | 全员参与 | QC 人员 |

### 质量成本 (COQ)

| 类别 | 示例 |
|------|------|
| 预防成本（最小） | 培训、设备、流程设计 |
| 评估成本 | 检查、测试、破坏性试验 |
| 内部失败成本 | 返工、废品 |
| 外部失败成本（最贵） | 保修、法律诉讼、商誉损失 |

### 质量工具

| 工具 | 用途 |
|------|------|
| 鱼骨图（因果图） | 找根本原因 |
| 帕累托图 | 80/20 法则 — 少数原因造成多数问题 |
| 控制图 | 判断过程是否受控（7 点规则） |
| 流程图 | 可视化过程步骤 |
| 直方图 | 展示数据分布 |
| 散点图 | 分析两个变量间的相关性 |

| 过程 | 过程组 | 核心输出 |
|------|--------|----------|
| 9.1 规划资源管理 | 规划 | 资源管理计划、**团队章程** |
| 9.2 估算活动资源 | 规划 | 资源需求、RBS |
| 9.3 获取资源 | 执行 | 资源日历、团队派工单 |

| 9.5 管理团队 | 执行 | 变更请求 |

### RACI 矩阵

| 字母 | 含义 |
|------|------|
| **R** (Responsible) | 执行 — 做事的人 |
| **A** (Accountable) | 负责 — 最终责任（每个活动仅一个 A） |
| **C** (Consult) | 咨询 — 双向沟通 |
| **I** (Inform) | 告知 — 单向通知 |

### Tuckman 团队发展模型

| 阶段 | 特征 | 领导风格 |
|------|------|----------|
| 形成 (Forming) | 相互认识、了解目标 | 指导型 |
| 震荡 (Storming) | 冲突出现、争夺角色 | 教练型 |
| 规范 (Norming) | 建立规则、开始协作 | 参与型 |
| 成熟 (Performing) | 高效自主工作 | 授权型 |
| 解散 (Adjourning) | 完成工作、释放资源 | — |

### 冲突解决策略（优先级从高到低）

| 策略 | 特征 |
|------|------|
| 1. 合作/解决问题 (Collaborate) | 双方共赢，最佳但最耗时 |
| 2. 妥协 (Compromise) | 各让一步，中等满意 |
| 3. 缓和 (Smooth) | 强调共识，淡化分歧 |
| 4. 强迫 (Force) | Win-Lose，紧急时使用 |
| 5. 回避 (Withdraw) | 暂时搁置，等情况冷却 |

## 沟通管理

| 过程 | 过程组 | 核心输出 |
|------|--------|----------|
| 10.1 规划沟通管理 | 规划 | 沟通管理计划 |
| 10.2 管理沟通 | 执行 | 项目沟通记录 |
| 10.3 监督沟通 | 监控 | 工作绩效信息 |

### 沟通方法

| 方法 | 类型 | 说明 | 效率 |
|------|------|------|------|
| 交互式沟通 | 双向实时 | 会议、电话、视频 | 最高 |
| 推式沟通 | 单向发送 | 邮件、报告、备忘录 | 中 |
| 拉式沟通 | 自行查阅 | 知识库、内网、资源库 | 被动 |

### 沟通渠道

> 沟通渠道数 = n(n-1) / 2（n = 干系人数量）

## 风险管理

| 过程 | 过程组 | 核心输出 |
|------|--------|----------|
| 11.1 规划风险管理 | 规划 | 风险管理计划 |
| 11.2 识别风险 | 全周期 | 风险登记册、风险报告 |
| 11.3 定性风险分析 | 规划 | 概率×影响矩阵 |
| 11.4 定量风险分析 | 规划 | EMV、蒙特卡洛模拟 |
| 11.5 规划风险应对 | 规划 | 风险应对计划 |
| 11.6 实施风险应对 | 执行 | 变更请求 |
| 11.7 监督风险 | 监控 | 更新的风险登记册 |

### 风险应对策略

| 威胁应对 | 含义 | 机会应对 | 含义 |
|----------|------|----------|------|
| 规避 | 消除威胁 | 开拓 | 确保实现 |
| 转移 | 转给第三方(保险) | 分享 | 与第三方共享 |
| 减轻 | 降低概率/影响 | 提高 | 增加概率/影响 |
| 接受 | 被动/主动接受 | 接受 | 不主动追求 |

## 采购管理

| 过程 | 过程组 | 核心输出 |
|------|--------|----------|
| 12.1 规划采购管理 | 规划 | 采购管理计划、SOW、招标文件 |
| 12.2 实施采购 | 执行 | 选定的卖方、合同 |

### 合同类型

| 合同类型 | 买方风险 | 范围明确度 |
|----------|----------|------------|
| 固定总价 (FFP) | 最低 | 范围明确 |
| 成本+固定费 (CPFF) | 中 | 范围不确定 |
| 成本+激励费 (CPIF) | 中高 | 中等 |
| 工料合同 (T&M) | 双方共担 | 范围不明确 |

### 权力/利益方格

| 高权力 + 高利益 | → **密切管理** (Manage Closely) |
| 高权力 + 低利益 | → **令其满意** (Keep Satisfied) |
| 低权力 + 高利益 | → **随时告知** (Keep Informed) |
| 低权力 + 低利益 | → **监督** (Monitor) |
