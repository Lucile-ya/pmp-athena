# 1.3 项目经理角色

## 项目经理的定义

项目经理是由**执行组织**委派，领导团队实现项目目标的个人。
- 由**发起人**授权，对项目结果负责
- **尽早任命**，最晚在规划开始前任命

## 项目经理的能力三角 (PMI Talent Triangle)

| 能力维度 | 占比/重点 | 说明 |
|----------|----------|------|
| 技术项目管理 | 基础能力 | 项目管理的技术知识、工具与技术 |
| 领导力 | 核心 | 指导、激励、赋能团队 |
| 战略与商业管理 | 视野 | 理解组织战略，确保项目对齐 |

## 领导力 vs 管理

| | 管理 (Management) | 领导力 (Leadership) |
|------|-------------------|---------------------|
| 关注 | 系统、流程、控制 | 愿景、人、关系 |
| 方式 | 维持秩序、遵守规则 | 创新、赋能、激发 |
| 权力来源 | 职位赋予 | 信任与影响力 |

## 项目经理的核心技能

| 技能 | 说明 |
|------|------|
| 沟通 | 90% 的时间用于沟通 |
| 谈判 | 获取资源、处理冲突、签订合同 |
| 冲突管理 | 识别冲突来源，选择适当策略 |
| 情商 (EQ) | 自我认知/自我管理/社会认知/关系管理 |
| 决策 | 在信息不完整时做出最佳决策 |
| 仆人式领导 | 服务团队，清除障碍（敏捷中核心） |

## 项目经理的整合角色

项目经理是**整合者**，需要：
1. 整合过程 — 确保各知识领域协调一致
2. 整合知识 — 连接不同来源的信息
3. 整合人员 — 协调各干系人的期望和需求
4. 整合变更 — 确保变更有序进行
