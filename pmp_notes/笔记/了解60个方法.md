# PMP 60 个方法速查

## 数据收集方法

| 方法 | 说明 |
|------|------|
| 头脑风暴 | 产生大量创意 |
| 访谈 | 一对一深度交流 |
| 焦点小组 | 召集干系人集体讨论 |
| 问卷调查 | 大规模快速收集 |
| 标杆对照 | 参照最佳实践 |
| 核对单 | 确保不遗漏的检查表 |

## 数据分析方法

| 方法 | 说明 |
|------|------|
| 挣值分析 (EVM) | CV/SV/CPI/SPI 综合分析 |
| 偏差分析 | 对比实际与基准 |
| 趋势分析 | 根据历史预测未来 |
| 根本原因分析 | 找根本原因（非表象） |
| 备选方案分析 | 评估多个可选的行动方案 |
| 成本效益分析 | 比较成本与预期收益 |
| SWOT 分析 | 优势/劣势/机会/威胁 |
| 假设条件和制约因素分析 | 验证假设的有效性 |
| 风险数据质量评估 | 风险数据的准确性和可靠性 |
| 敏感性分析 | 确定影响最大的变量（龙卷风图） |
| 决策树分析 | EMV = 概率 × 影响 |
| 影响图 | 可视化变量间的因果关系 |
| 储备分析 | 剩余储备是否充足 |
| 回归分析 | 变量间的数学关系 |

## 决策方法

| 方法 | 说明 |
|------|------|
| 投票 | 多数原则 |
| 独裁决策 | 一人做决定 |
| 多标准决策分析 | 按权重多维度评分 |

## 人际关系与团队技能

| 方法 | 说明 |
|------|------|
| 冲突管理 | 合作/妥协/缓和/强迫/回避 |
| 谈判 | 达成共识、获取资源 |
| 积极倾听 | 反馈、澄清、确认 |
| 情商 | 自我认知+管理+社会认知+关系管理 |
| 领导力 | 愿景引导、赋能团队 |
| 决策 | 信息不完整时做出最佳选择 |
| 团队建设 | 培训、团建活动、认可奖励 |
| 影响力 | 说服干系人支持项目 |
| 激励 | 满足团队成员的需求 |
| 教练 | 引导团队成员成长 |
| 政治意识 | 理解组织内的权力结构 |
