# 2.2 项目规划（上）— 范围、进度、成本

## 范围管理 (Scope Management)

确保项目做且**只做**该做的事。

| 过程 | 过程组 | 核心输出 |
|------|--------|----------|
| 5.1 规划范围管理 | 规划 | 范围管理计划、需求管理计划 |
| 5.2 收集需求 | 规划 | 需求文件、需求跟踪矩阵 |
| 5.3 定义范围 | 规划 | 项目范围说明书 |
| 5.4 创建 WBS | 规划 | WBS、WBS 词典、**范围基准** |
| 5.5 确认范围 | 监控 | 验收的可交付成果 |
| 5.6 控制范围 | 监控 | 工作绩效信息、变更请求 |

### 需求收集工具

| 工具 | 说明 |
|------|------|
| 访谈 | 一对一深度交流 |
| 焦点小组 | 召集干系人集体讨论 |
| 引导式研讨会 | 跨职能一起定义需求 |
| 问卷调查 | 大量受众快速收集 |
| 标杆对照 | 参照最佳实践 |
| 原型法 | 制作模型验证需求 |

### WBS (工作分解结构)

| 概念 | 说明 |
|------|------|
| WBS | 将可交付成果和工作逐层分解为工作包 |
| 工作包 | WBS 的最底层，可估算成本和持续时间的单元 |
| 控制账户 | 管理控制点，合并范围/预算/进度 |
| 100% 规则 | WBS 涵盖项目 100% 的工作 |
| 范围基准 | **WBS + WBS 词典 + 范围说明书** |

## 进度管理 (Schedule Management)

| 过程 | 过程组 | 核心输出 |
|------|--------|----------|
| 6.1 规划进度管理 | 规划 | 进度管理计划 |
| 6.2 定义活动 | 规划 | 活动清单、里程碑清单 |
| 6.3 排列活动顺序 | 规划 | 进度网络图 (PDM) |
| 6.4 估算活动持续时间 | 规划 | 持续时间估算 |
| 6.5 制定进度计划 | 规划 | **进度基准**、项目进度计划 |
| 6.6 控制进度 | 监控 | 工作绩效信息、进度预测 |

### 估算方法对比

| 方法 | 准确度 | 适用阶段 | 说明 |
|------|--------|----------|------|
| 类比估算 | 低 (-25%~+75%) | 启动/早期 | 基于历史类似项目，快速粗略 |
| 参数估算 | 中 | 规划 | 基于历史数据+统计公式 |
| 三点估算 | 中高 | 规划 | 乐观+最可能+悲观 ÷ 加权 |
| 自下而上估算 | 高 | 详细规划 | 从工作包逐层汇总，最准但最费时 |

### 关键路径法 (CPM)

| 概念 | 定义 |
|------|------|
| 关键路径 | 网络图中最长的路径 = 项目最短完成时间 |
| 总浮动时间 | 活动可推迟而不影响总工期的时间 |
| 自由浮动时间 | 活动可推迟而不影响紧后活动最早开始的时间 |
| 关键路径上的活动总浮动时间 = 0 |

### 进度压缩

| 技术 | 原理 | 副作用 |
|------|------|--------|
| **赶工** (Crashing) | 增加资源 | **增加成本**，适用于资源驱动型活动 |
| **快速跟进** (Fast Tracking) | 并行开展活动 | **增加风险**，可能需返工 |

### 挣值管理 (EVM) 核心公式

| 指标 | 公式 | 理解 |
|------|------|------|
| **CV** (成本偏差) | EV - AC | >0 节约，<0 超支 |
| **SV** (进度偏差) | EV - PV | >0 提前，<0 落后 |
| **CPI** (成本绩效指数) | EV / AC | >1 节约，<1 超支 |
| **SPI** (进度绩效指数) | EV / PV | >1 提前，<1 落后 |
| **TCPI** (完工尚需绩效指数) | (BAC-EV)/(BAC-AC) | 剩余工作需达到的效率 |
| **EAC** (完工估算) | AC + (BAC-EV)/CPI | 按当前效率预计最终成本 |

### 储备分析

| 类型 | 针对 | 谁控制 | 是否在基准内 |
|------|------|--------|-------------|
| 应急储备 | 已知风险 | 项目经理 | 是（成本基准包含） |
| 管理储备 | 未知风险 | 发起人/管理层 | 否（使用需变更基准） |
