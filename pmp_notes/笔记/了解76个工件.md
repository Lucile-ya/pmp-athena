# PMP 76 个工件速查

## 核心规划文档

| 工件 | 来源过程 | 用途 |
|------|----------|------|
| 项目章程 | 4.1 制定项目章程 | 授权项目、任命项目经理 |
| 项目管理计划 | 4.2 制定项目管理计划 | 统一的项目主计划 |
| 范围管理计划 | 5.1 规划范围管理 | 如何定义、验证、控制范围 |
| 需求管理计划 | 5.1 规划范围管理 | 如何收集和管理需求 |
| 进度管理计划 | 6.1 规划进度管理 | 如何制定、监控进度 |
| 成本管理计划 | 7.1 规划成本管理 | 如何估算、预算、控制成本 |
| 质量管理计划 | 8.1 规划质量管理 | 质量标准与改进方法 |
| 资源管理计划 | 9.1 规划资源管理 | 如何管理实物资源和团队 |
| 沟通管理计划 | 10.1 规划沟通管理 | 谁需要什么信息、何时、如何 |
| 风险管理计划 | 11.1 规划风险管理 | 风险管理策略和角色 |
| 采购管理计划 | 12.1 规划采购管理 | 采购策略与合同类型 |
| 干系人参与计划 | 13.2 规划干系人参与 | 如何调动干系人参与 |

## 三大基准

| 基准 | 组成 | 变更须经 |
|------|------|----------|
| 范围基准 | WBS + WBS词典 + 范围说明书 | CCB |
| 进度基准 | 经批准的进度计划 | CCB |
| 成本基准 | 经批准的分时段预算（含应急储备） | CCB |

## 关键登记册/日志

| 工件 | 用途 |
|------|------|
| 风险登记册 | 记录已识别风险、分析结果、应对计划 |
| 干系人登记册 | 干系人身份、评估信息、分类 |
| 问题日志 | 记录已发生的问题和解决方案 |
| 假设日志 | 记录假设条件和制约因素 |
| 经验教训登记册 | 记录项目过程中的经验教训 |
| 变更日志 | 记录所有变更请求及其状态 |

## 关键绩效文档

| 工件 | 来源 | 内容 |
|------|------|------|
