# PMP11 利益相关方（干系人）管理

> 来源：骐迹教育第 11 讲。People 域；与沟通管理边界是高频坑。

## 一、绩效域在干什么

有效干系人参与：识别 → 理解分析 → 排序 → 参与 → 监督。  
翻译演变：干系人 / 相关方 / 利益相关方，考试概念同一。

## 二、参与过程链

| 步骤 | 要点 |
|------|------|
| 识别 | 谁影响或被影响；含隐性干系人 |
| 理解与分析 | 利益、态度、权力、影响、期望 |
| 优先级排序 | 有限精力先密管关键干系人 |
| 参与 Engage | 按策略沟通与拉齐 |
| 监督 | 参与度是否达期望，调策略 |

新干系人出现：**先沟通了解**，再更新登记册（先人后工具）。

## 三、权力/利益方格

| | 高利益 | 低利益 |
|--|--------|--------|
| **高权力** | 密切管理 | 令其满意 |
| **低权力** | 随时告知 | 监督即可 |

## 四、参与度评估矩阵

- **C** = 当前参与水平  
- **D** = 期望参与水平（成功所需）  
- 差距 → 调整参与策略与沟通  

参与水平常见：不了解 / 抵制 / 中立 / 支持 / 领导。

## 五、沟通方法与模型

| 方法 | 含义 |
|------|------|
| 交互式 | 双向实时（会议、电话）— 复杂问题优先 |
| 推式 | 发出去但不确保理解（邮件、报告） |
| 拉式 | 自行查阅（门户、知识库） |

沟通模型：发送方编码 → 媒介 → 接收方解码；噪声、反馈闭环。

## 六、沟通 vs 干系人管理（考试技巧）

用 **5W** 检查沟通是否到位：What / How / When / How often / Who。

| 情况 | 判为 |
|------|------|
| 5W 没做到 | **沟通管理**问题 |
| 5W 都做到了仍不满意 | **干系人参与/管理**问题 |

**口诀：先查沟通有没有做对；做对了还闹，再查参与策略。**

## 七、会议管理

议程、角色、时间盒、决策与行动项记录、会后跟进——减少无效会。

## 八、易错对照

| 题干信号 | 选这 | 别选那 |
|----------|------|--------|
| 新出现的高管干系人 | 会面了解需求 | 先改系统登记完事 |
| 邮件发了对方仍怒 | 面对面/交互式 + 分析参与 | 继续群发报告 |
| 高权高利抵制 | 密切管理、合作解决顾虑 | 强推或无视 |
