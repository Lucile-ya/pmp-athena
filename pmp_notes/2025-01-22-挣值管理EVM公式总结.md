## 挣值管理 (Earned Value Management) 核心公式

### 三个基本值

| 缩写 | 全称 | 含义 |
|------|------|------|
| PV | Planned Value | 计划价值——计划完成工作的预算 |
| EV | Earned Value | 挣值——实际完成工作的预算（核心！） |
| AC | Actual Cost | 实际成本——实际花费 |

### 偏差分析

- **SV = EV - PV**（进度偏差）
  - SV > 0：进度超前
  - SV < 0：进度滞后
- **CV = EV - AC**（成本偏差）
  - CV > 0：成本节约
  - CV < 0：成本超支

### 绩效指数

- **SPI = EV / PV**（进度绩效指数）
  - SPI > 1：进度超前
  - SPI < 1：进度滞后
- **CPI = EV / AC**（成本绩效指数）
  - CPI > 1：成本节约
  - CPI < 1：成本超支

### 预测 (ETC/EAC)

- **ETC = (BAC - EV) / CPI**（考虑 CPI 的完工尚需估算）
- **EAC = AC + ETC = BAC / CPI**（完工估算，最常用公式）
- **TCPI = (BAC - EV) / (BAC - AC)**（完工尚需绩效指数）
  - TCPI > 1：需要比计划更高的效率才能完成

### 记忆技巧

> "EV 比 PV 大就超前，EV 比 AC 大就省钱"
> 
> "SV/CV 用减的，SPI/CPI 用除的"
>
> "EAC 四个公式：BAC/CPI, AC+BAC-EV, AC+新估算, AC+(BAC-EV)/(CPI×SPI)"

### 典型考题陷阱

1. **问 EAC 用哪个公式**：如果题目说"当前偏差将继续"，用 BAC/CPI
2. **TCPI 分母是 BAC-AC 还是 EAC-AC**：看题目用哪个预算（原预算 or 新 EAC）
3. **SPI 和 CPI 同时出现时**：SPI 看是否按时，CPI 看是否超支
