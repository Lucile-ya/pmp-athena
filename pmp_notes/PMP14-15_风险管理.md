# PMP14-15 风险管理

> 来源：骐迹教育第 14–15 讲课件摘要（非原文 OCR）。考场优先记表格与口诀。

## 一、风险绩效域在考什么

项目处在不确定性中。不确定性表现为**威胁**与**机会**。  
已发生的消极情况 → **问题（Issue）**，不是风险。

有效执行此绩效域，预期包括：

- 了解运行环境（技术/社会/政治/市场/经济）
- 主动探索并应对不确定性
- 能预测威胁与机会，并理解问题后果
- 交付少受不可预见事件冲击
- 利用机会改进成果
- 合理使用成本/进度储备，对齐目标

## 二、基本概念对照

| 概念 | 含义 | 考试别踩 |
|------|------|----------|
| 风险 Risk | 不确定事件/条件，发生后对目标有正或负影响 | 「可能」→ 风险登记册 |
| 问题 Issue | 已经存在的状态，可能已影响目标 | 「已经/当前」→ 问题日志 |
| 威胁 Threat | 消极风险 | 规避/转移/减轻/接受/上报 |
| 机会 Opportunity | 积极风险 | 开拓/分享/提高/接受/上报 |

**口诀：可能进风险册，已经进问题日志。**

## 三、风险三要素与期望值

| 要素 | 含义 |
|------|------|
| 事件 Event | 可能发生什么 |
| 概率 Probability | 发生可能性 |
| 影响 Impact | 发生后的后果（金额 at stake） |

\[
\text{期望值 / 风险敞口} = P \times I
\]

## 四、整体风险 vs 单个风险

| | 整体项目风险 | 单个项目风险 |
|--|--------------|--------------|
| 含义 | 不确定性对**整个项目**的综合影响 | 具体某一事件/条件 |
| 来源 | 多个单风险 + 复杂性/模糊性/易变性 | 识别清单中的一条条 |
| 过高时 | 组织可选择取消项目 | 逐条规划应对 |

影响组织风险态度的三因素：

| 术语 | 含义 |
|------|------|
| 风险偏好 Appetite | 为回报愿意承担不确定性的程度（逃避/中立/热衷） |
| 风险承受力 Tolerance | 主观能忍到哪 |
| 风险临界值 Threshold | 客观可接受偏差；应明确并写入影响级别定义 |

## 五、识别工具速记

| 工具/来源 | 用途 |
|-----------|------|
| 协议/合同 | 里程碑、合同类型、奖罚条款中的风险 |
| 采购文档 | 外购可能抬高或降低整体风险 |
| 章程/范围说明书/WBS 词典/活动属性 | 假设与制约 → 风险来源 |
| 头脑风暴 / 核对单 / SWOT | 集思广益、历史比对、内外因素 |
| PESTLE | 政治/经济/社会/技术/法律/环境 · 宏观来源 |
| VUCA | 易变 Volatility · 不确定 Uncertainty · 复杂 Complexity · 模糊 Ambiguity |

## 六、风险登记册 vs 风险报告

**风险登记册**常见字段：

1. 名称与描述  
2. 概率与影响  
3. 风险责任人  
4. 优先级  
5. 应对方案（含弹回计划、应急应对策略）

**风险报告**：整体风险敞口 + 已识别单风险概述（渐进完善）。

## 七、应急储备 vs 管理储备

| | 应急储备 | 管理储备 |
|--|----------|----------|
| 针对 | **已知风险**（known unknowns） | **未知风险**（unknown unknowns） |
| 谁用 | 通常在基准内，PM 可按计划使用 | 不在成本基准内，动用常需变更 |
| 考试 | 已识别风险的钱/时间 | 「没想到的」才动管理储备 |

**口诀：已知用应急，未知用管理；管理储备动基准要变更。**

（讲义个别页表述易混，以上按 PMBOK/考试口径。）

## 八、风险管理过程（7）

| # | 过程 | 过程组 | 一句话 |
|---|------|--------|--------|
| 11.1 | 规划风险管理 | 规划 | 定义怎么管风险 → **风险管理计划** |
| 11.2 | 识别风险 | 规划 | 找出威胁与机会 → 登记册 |
| 11.3 | 实施定性风险分析 | 规划 | 概率×影响排序，定责任人 |
| 11.4 | 实施定量风险分析 | 规划 | 数值分析（可选，复杂项目） |
| 11.5 | 规划风险应对 | 规划 | 选策略、分配资源 |
| 11.6 | 实施风险应对 | 执行 | 按计划执行应对 |
| 11.7 | 监督风险 | 监控 | 跟踪、识别新风险、储备是否够 |

概率影响矩阵的**定义**在 **规划风险管理** 完成，不是识别/定性时才临时定。

## 九、威胁应对（5）

| 策略 | 要点 | 信号 |
|------|------|------|
| 规避 Avoid | 消除威胁或使概率≈0 | 改策略、缩范围、延进度 |
| 转移 Transfer | 责任与影响转第三方 | 保险、固定价、履约保函 |
| 减轻 Mitigate | 降概率和/或影响 | 测试、稳供应商、原型 |
| 接受 Accept | 主动=留应急；被动=盯着不行动 | 低优先级或不经济 |
| 上报 Escalate | 超项目范围或超 PM 权限 | 上报后本项目不再主责管理 |

## 十、机会应对（5）

| 策略 | 要点 |
|------|------|
| 开拓 Exploit | 使机会几乎必然发生（概率→100%） |
| 分享 Share | 与最能获利的第三方共担/共享 |
| 提高 Enhance | 提高概率或扩大正面影响 |
| 接受 Accept | 承认机会，可不主动规划 |
| 上报 Escalate | 同威胁：超范围/超权限 |

相关术语：

- **次生风险**：因应对 A 而产生的新风险 B  
- **残余风险**：应对后仍可能出现的 A（通常更小）  
- **应急应对策略**：有预警信号才触发的计划  
- **弹回计划**：主应对失败后的后备方案  

## 十一、定量常见手法（认名即可）

| 工具 | 常考用途 |
|------|----------|
| 蒙特卡洛模拟 | 多次迭代 → S 曲线累积概率 |
| 敏感性分析 | 哪个风险对结果影响最大（龙卷风图） |
| 决策树 | 含决策节点的期望货币值 |
| 影响图 | 变量因果关系 |

## 十二、敏捷/混合里的风险

- 日站会：阻碍拖久了可能变威胁；突破可能是机会  
- 演示/评审负面反馈：干系人不满的早期信号  
- 回顾会：找威胁绩效与改进机会  
- 无论环境，都用**风险登记册**登记、更新、关闭  

## 十三、易错对照（结合你的错题）

| 题干信号 | 选这 | 别选那 |
|----------|------|--------|
| 「可能」延迟/发生 | 更新风险登记册 | 直接改进度/当问题 |
| 「已经」发生 | 问题日志 + 纠正 | 只写风险册 |
| 新强制合规（执行中） | 先识别/分析风险或更新相关方与计划链 | 跳过评估直接干 |
| 法规必须过才能上市 | 守规 + 压缩进度 | 找例外、只请专家做计划 |

## 十四、考场 30 秒口诀

1. **可能→风险册；已经→问题日志**  
2. **已知应急，未知管理**  
3. **威胁：规避转移减轻接受上报**  
4. **机会：开拓分享提高接受上报**  
5. **超权限就上报，上报后本项目不再主责**  
6. **定性排优先级，定量算数值（蒙特卡洛/敏感性）**
