# PMP5-6 项目治理绩效域

> 来源：骐迹教育第 5–6 讲。覆盖启动、变更、采购步骤、度量、收尾——整合/治理高频。

## 一、治理模型

| 模型 | 特点 |
|------|------|
| 结构化治理 | 发起人、PMO、治理委员会等明确角色与审批链 |
| 自我治理 | 可能无专职 PMO 负责人，PM 群体共担绩效优化 |

治理 = **决策权、升级路径、合规与标准**；PM 在授权内执行，超权上报。

## 二、启动要点

| 要素 | 要点 |
|------|------|
| 商业论证 | 业务需要 → 形势分析 → 推荐 → 评估 |
| 项目章程 | 发起人签发，正式授权 PM 动用资源 |
| 假设日志 | 记录假设与制约，后续验证 |
| 专家判断 / 访谈 | 识别干系人、边界、风险与成功标准 |

**口诀：没章程没授权；商业论证回答「为什么做」。**

## 三、度量绩效域（SMART）

有效度量指标特征（SMART）：具体、可测、可达成、相关、有时限。  
显示方式：仪表盘、燃尽/燃起、进度图、基线绩效（SV/SPI 等）。

## 四、变更控制（必背顺序）

1. 意向沟通 / 了解变更诉求（分析前先弄清）  
2. 正式提出变更请求，记入**变更日志**  
3. **评估影响**（范围/进度/成本/质量/风险/资源）  
4. 审批：不涉及基准/章程/合同/管理储备 → 常由 PM；涉及 → **CCB**  
5. 批准后实施；更新基准与文件  
6. 总结经验教训  

**口诀：评估 → 提交 → 批准后才干；CCB 前禁止执行。**

## 五、采购步骤（10 步骨架）

1. 准备 SOW/TOR  
2. 高层级成本估算与预算  
3. 发布招标广告  
4. 合格卖方短名单  
5. 准备并发布招标文件  
6. 卖方提交建议书  
7. 技术（含质量）评估  
8. 成本评估  
9. 综合评估报告  
10. 谈判结束，签署合同  

## 六、收尾

| 类型 | 要点 |
|------|------|
| 预测型收尾 | 验收、移交、行政收尾、释放资源、经验教训、合同收尾 |
| 适应型收尾 | 增量验收贯穿始终；最终仍要产品移交与组织收尾动作 |

## 七、易错对照

| 题干信号 | 选这 | 别选那 |
|----------|------|--------|
| 客户口头加需求 | 走变更/记 CR | 立刻开发讨好 |
| 未批就改基准 | 停 → 补流程 | 先改再补手续 |
| 收尾后客户还要大改 | 新项目/新章程或正式变更评估 | 当原项目无偿追加 |
