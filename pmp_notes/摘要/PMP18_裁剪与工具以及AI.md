# PMP18 裁剪与工具以及 AI

> 来源：骐迹教育第 18 讲（第八版）。新版必考点：**裁剪四步 + AI 采用策略/伦理 + 变革模型速记**。先背口诀再翻 PDF。

## 一、AI（先拿分）

| 概念 | 一句话 |
|------|--------|
| AI | 广义：推理、学习、自主行动 |
| ML | 用数据训练，预测输出 |
| DL | 多层神经网络，要大数据算力 |
| GenAI | 生成新文本/图/音/视频 |

### 采用三层

| 层 | 含义 | 例子 |
|----|------|------|
| **自动化** | 低复杂度、几乎不需人干预 | 报告生成、纪要总结 |
| **协助** | 辅助分析、迭代逼近；**首轮结果不能当终稿** | 风险登记册草稿、进度草案 → **人审** |
| **增强** | 战略/复杂权衡与新能力 | 组合备选方案、外部变量风险预测；当头脑风暴伙伴多轮迭代 |

### 伦理八关（决策责任在人）

偏见 · 隐私 · 担当（**最终责任必须是人**）· 可靠性（要验证）· 安全性 · 透明度 · 版权 · 可持续性（算力/水电）

**口诀：AI 能辅助不能替责；协助层必须人审；增强层当搭档迭代。**

## 二、裁剪是什么

深思熟虑后调整方法/治理/过程，使之更适合当前环境与工作。  
可：**增加 / 修改 / 取消 / 混合 / 调整**。  
替代方案＝原样套框架（新手常犯：不顾规模复杂度硬套）。

### 为什么裁剪

过程太少漏关键活动；太多则浪费。  
按规模、工期、复杂性、行业、文化、成熟度裁。  
收益：团队承诺、以客户为本、资源更有效。

### 可裁剪五块

1. 生命周期与开发方法  
2. 过程  
3. 参与（人/赋能/整合外部贡献者）  
4. 工具  
5. 方法与工件  

混合例：数据中心＝建筑预测型 + 算力迭代型 → 项目层混合。

### 过程怎么动

| 动作 | 例 |
|------|----|
| 增加 | 高安全项目加独立检查 |
| 修改 | 改文档格式照顾视力 |
| 取消 | 小团队共址可取消会议纪要 |
| 混合 | 经验教训会加欣赏式探询 |
| 调整 | 多学科风险管理语言对齐 |

## 三、裁剪四步（必背）

1. **选初始开发方法**（合适性筛选器 → 预测/混合/适应）  
2. **对组织裁剪**（服从政策/合同/高安全监督；PMO 审批；适应型组织可有 **VDO**=教练赋能非官僚管控）  
3. **对项目裁剪**（产品、团队、文化属性提问后定参与/过程/工具）  
4. **持续改进**（阶段关口、回顾；裁剪不是一次性）

### 项目裁剪看三类属性

| 类 | 关键问题 |
|----|----------|
| 产品/交付物 | 合规严格度、有形/无形、监管市场、技术成熟度、工期、需求稳定性、保密、能否增量 |
| 团队 | 规模、地理/远程、经验、能否及时获客户反馈 |
| 文化 | 认同、信任、赋能、与组织价值观是否一致 |

合同或政策强制某种方法时 → 裁剪空间变小，仍记「合规优先」。

## 四、工具/模型速记（情景题信号）

| 模型 | 考场用法 |
|------|----------|
| **ADKAR** | 个人变革五步：认知→渴望→知识→能力→巩固 |
| **Bridges 转变** | 变革是情境；转变是心理：结束/失去 → 中间区 → 新开始 |
| **OCM 五要素** | 启动→规划→实施→管理过渡→维持（带反馈环） |
| **OSCAR** | 教练：成果·情境·选择/后果·行动·评审 |
| **X/Y/Z 理论** | X 外驱管控；Y 内驱教练；Z 自我实现/终身福利取向 |
| **Cynefin** | 简单感-分类-响应；繁杂感-分析-响应；复杂探-感-响应；混乱先行动再建秩序 |
| **Boehm 七原则** | 分阶段计划、持续确认、配置控制、现代实践、清晰责任、少而精、过程改进 |

## 五、易错对照

| 题干信号 | 选这 | 别选那 |
|----------|------|--------|
| AI 出了方案就落地 | 人审 / 明确人类最终责任 | 全自动拍板 |
| 小项目硬套大方法论 | 裁剪（取消/简化） | 「必须完整遵守」 |
| 组织强制瀑布 | 在约束内裁剪 / 证明合理性 | 无视政策自创敏捷 |
| 适应型组织设办公室 | VDO 教练赋能 | 当成强管控 PMO |
| 变革个人不配合 | ADKAR / 转变阶段 | 只发通知强制 |
| 因果不清的危机 | Cynefin 混乱：先行动 | 先做完整分析再动 |
