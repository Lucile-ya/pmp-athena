# 过程组：实践指南 · 摘要

> 配套 PMBOK7 的**预测型**实操：五大过程组 × 约 49 过程。

## 你要用它干什么

| 场景 | 用法 |
|------|------|
| 题干很「瀑布」 | 用过程组定位现在在哪一步 |
| 问输入/工具/输出 | 先定过程，再想 ITTO |
| 变更/收尾/监控 | 对到整合 4.5/4.6/4.7 |

| 过程组 | 一句话 |
|--------|--------|
| 启动 | 授权项目，识别干系人 |
