# PMP8-9 进度管理

> 来源：骐迹教育第 8–9 讲。关键路径、浮动、压缩——计算与情景都考。

## 一、过程骨架

| # | 过程 | 一句话 |
|---|------|--------|
| 6.1 | 规划进度管理 | 怎么管进度 → 进度管理计划 |
| 6.2 | 定义活动 | WBS 工作包 → 活动清单（动词） |
| 6.3 | 排列活动顺序 | PDM 网络图、依赖、提前量/滞后量 |
| 6.4 | 估算活动持续时间 | 类比/参数/三点/自下而上 |
| 6.5 | 制定进度计划 | 关键路径、资源优化、基准 |
| 6.6 | 控制进度 | 对照基准，赶工/快速跟进等 |

**口诀：WBS 是名词交付物；定义活动才出动词任务。**

## 二、依赖与 PDM

| 类型 | 含义 |
|------|------|
| FS | 完成后才能开始（最常见） |
| SS | 同时开始类 |
| FF | 同时完成类 |
| SF | 少见：开始后才能完成 |

依赖：强制 / 选择 / 外部 / 内部。

## 三、估算

| 方法 | 场景 |
|------|------|
| 类比 | 早期、粗、快，靠相似项目 |
| 参数 | 历史数据 × 公式 |
| 三点（PERT） | 乐观/最可能/悲观 → 期望与标准差 |
| 自下而上 | 最准、最费时 |

估算依据 Basis of Estimates：方法、假设、置信区间等要留下。

## 四、关键路径与浮动

| 概念 | 含义 |
|------|------|
| 关键路径 | 最长路径；决定最短工期 |
| 总浮动 | 不影响项目完工可推迟量；关键路径通常为 0 |
| 负浮动 | 无法满足约束完工 → 需压缩/改约束 |
| 自由浮动 | 不影响紧后最早开始可推迟量 |

**口诀：关键路径上拖一天，项目晚一天。**

## 五、缩短工期

| 技术 | 做法 | 代价 |
|------|------|------|
| 赶工 Crashing | 加资源缩短关键活动 | 成本↑ |
| 快速跟进 Fast Tracking | 并行原串行活动 | 风险↑、返工↑ |

先评估影响，优先关键路径上的活动。

## 六、控制进度工具

- 绩效审查、趋势、挣值（SPI/SV）  
- 资源优化、模拟（蒙特卡洛）  
- 敏捷：燃尽图、迭代燃尽、发布规划  
- 横道图（甘特）、逻辑横道图  

## 七、易错对照

| 题干信号 | 选这 | 别选那 |
|----------|------|--------|
| 负浮动 | 评估后压缩/改计划 | 假装能按原期完工 |
| 要缩短且预算紧 | 快速跟进（知风险）或减范围经批准 | 无脑全面赶工 |
| 关键里程碑未完成 | 根因 + 进度压缩选项评估 | 先减范围不分析 |
| 合同刚签完 | 检查活动/网络/估算是否纳入 | 「与进度无关」 |
