# PMBOK® 指南 第 8 版 · 考场要点

> 官方全书不背。只记与考试决策相关的骨架（摘要，非原文）。

## 相对第 7 版你要抓住的变化

| 主题 | 第 8 版方向（摘要） |
|------|---------------------|
| 原则 | 简化为约 **6 项可操作原则**（负责任领导、价值、质量、可持续性、赋权文化等） |
| 过程组 | 重新表述为更实用的**关注领域** |
| 绩效域 | **7 个**项目绩效域 + 演进流程（含财务等） |
| 焦点 | 价值交付 > 只交产出 |

## 价值交付系统（必懂）

战略/愿景 → 组合 → 项目集/产品/项目 → 运营  
信息上下流动；度量反馈调优先级。

## 开发方法裁剪

需求稳定度、创新度、法规、团队成熟度、干系人参与频率 → 选预测 / 适应 / 混合。

## 与 ECO 怎么对

- ECO 考情景判断，不完全考背 PMBOK 章节号  
- 第 8 版语言（价值、可持续、财务绩效域）会渗进新题  
- 过程细节仍可用「五大过程组×十大领域」骨架（见思维导图摘要）

**口诀：第 8 版抓价值与原则；做题流程骨架仍可用过程组地图。**
