# PMP12-13 资源与团队管理

> 来源：骐迹教育第 12–13 讲。冲突、激励、RACI、团队章程——People 核心。

## 一、资源绩效域 vs 团队绩效域

| | 资源 | 团队 |
|--|------|------|
| 焦点 | 物理资源 + 人力资源获取与利用 | 领导力、文化、协作、高绩效 |
| 工具例 | 估算、获取、资源日历 | 团队章程、激励、冲突、情商 |

## 二、领导：集中式 vs 分布式

| | 集中式 | 分布式 |
|--|--------|--------|
| 特点 | 职责较集中在 PM | 领导力分散在团队（敏捷常见） |
| 裁剪 | 依文化、成熟度、项目类型 | 仆人式领导、引导而非命令 |

## 三、OBS / RACI

- **OBS**：按组织单元看项目职责  
- **RACI**：R 执行 / A 问责（唯一）/ C 咨询 / I 知情  

**口诀：A 只能一个；R 可多人。**

## 四、组建与发展

| 主题 | 要点 |
|------|------|
| 获取资源 | 预分派、谈判、采购、虚拟团队 |
| Tuckman | 形成 → 震荡 → 规范 → 成熟 → 解散 |
| 团队章程 | 价值观、协议、会议、冲突规则——团队共建 |
| 愿景 | 对齐目标与「为何而战」 |
| 虚拟团队 | 沟通协议、时区、协作工具、信任 |

## 五、激励

- 内在激励（成就、成长、自主）往往更持久  
- 表彰：**贯穿生命周期**，不要只等项目结束  
- 了解双因素、期望理论等「认名+场景」即可  

## 六、决策与情商

| 决策方式 | 场景 |
|----------|------|
| 单方面 | 紧急、低影响或授权内 |
| 群体决策 | 需知识广度与承诺 |
| 发散/汇聚 | 先拓宽选项再收敛 |

情商：自知、自律、社交、共情——冲突与影响力基础。

## 七、冲突解决（优先级）

考试默认优先序（由佳到次）：

1. **合作/解决问题**（双赢）  
2. 妥协  
3. 缓和/包容  
4. 强迫/支配  
5. 撤退/回避  

**口诀：先合作，逼迫垫底；撤退仅缓冲。**

冲突来源常：进度、项目优先级、资源、技术意见、行政程序、个性。

## 八、易错对照

| 题干信号 | 选这 | 别选那 |
|----------|------|--------|
| 两人技术争执 | 合作/面对面对质问题 | 第一步找高管 |
| 矩阵抢人 | 与职能经理协商 | PM 强行命令 |
| 敏捷优先级谁定 | PO | SM 定优先级 |
| 只项目结束才表扬 | 过程中及时认可 | 等庆功会 |
