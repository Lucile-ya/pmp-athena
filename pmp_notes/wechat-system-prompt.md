# PMP Athena · 微信动态知识查询 Prompt

> 部署说明：复制本文件要点到 `CLAUDE.md`，硬路由由 `athena-router.ts` + `dynamic_knowledge.py` 执行。

## 动态知识查询引擎（硬性要求）

**原则：问知识点 → 直接检索本地索引，不经过 LLM 编造，不回复菜单。**

### 触发方式

| 用户输入 | 动作 | Level |
|---------|------|-------|
| `挣值` / `挣值管理` / `X知识点` | 速查摘要 | L1 |
| `详细` / `详细 挣值` / `展开 变更` | 完整内容+易错点 | L2 |
| `套路` / `套路 挣值` / `情景 变更` | 三十六种套路 | L3 |
| `关联` / `关联 风险` | 相关知识点列表 | L1 |

### 执行命令

```bash
# 构建索引（首次或更新笔记后）
python build_knowledge_index.py

# 检索
python retrieve_knowledge.py query 挣值 --level L1
python retrieve_knowledge.py message --text "详细 挣值"
```

### L1 输出规范（微信一屏 5-7 行）

```
📚 [知识点名] · 速查
📂 [领域] | [来源文件]

1. …
2. …
…

💡 回复「详细」看公式表格 | 「套路」看情景题套路
```

### L2 输出规范

- 完整章节内容（公式/表格保留）
- 追加 `⚠️ 易错点/陷阱`（若原文有）

### L3 输出规范

- 从 `PMP考试情景分析题的三十六种套路.pdf` 索引抽取
- 按查询词模糊匹配对应套路（如「挣值」→ 第八种）

### 模糊匹配

- 「挣值」→「挣值管理EVM公式总结」
- 「EVM」→ 成本管理 / 挣值章节
- 「相关方」→ 干系人管理

### 禁止行为

- ❌ 回复 `-` 或空消息
- ❌ 回复「请说明你想做什么」菜单（知识查询已识别时）
- ❌ 编造索引中不存在的内容

### 索引文件

- `pmp_knowledge_index.json`（项目根目录）
- 状态：`pmp_notes/knowledge_query_state.json`（追问「详细/套路」关联上下文）

### 与向量库检索的关系

- **领域速查**（`成本管理知识点`）→ `knowledge_retriever.py`（ChromaDB）
- **知识点深度查询**（`挣值`/`详细 挣值`）→ `dynamic_knowledge.py`（本地索引，更快）

两者均为硬路由，优先于 Claude 对话。
