# PMP4 开发方法和生命周期

> 来源：骐迹教育第 4 讲。预测≈40% / 敏捷+混合≈60%，每天练习要带情景题。

## 一、生命周期 vs 开发方法

| 概念 | 含义 |
|------|------|
| 项目生命周期 | 从开始到结束的一系列阶段；含交付节奏与开发方法所促成的阶段 |
| 开发方法 | 如何产出可交付物：预测型 / 适应型（敏捷）/ 混合型 |
| 交付节奏 | 一次性交付 / 多次交付 / 持续交付（含 CI/CD 思维） |

**口诀：生命周期管阶段节奏；开发方法管怎么做出来。**

## 二、三种方法对照

| | 预测型 Predictive | 适应型 Adaptive | 混合型 Hybrid |
|--|-------------------|-----------------|---------------|
| 需求 | 前期较清晰、稳定 | 演进、频繁反馈 | 部分稳定部分演进 |
| 规划 | 详细前期规划 | 滚动/迭代规划 | 按模块或阶段切换 |
| 变更 | 走变更控制 | 欢迎变更（Backlog） | 视模块规则 |
| 信号词 | WBS、基准、CCB、EVM | Sprint、PO、燃尽、DoD | 两类信号同时出现 |

## 三、混合常见四种模式（认名）

1. **预测外壳 + 敏捷内核**（阶段门内用迭代）  
2. **敏捷外壳 + 预测内核**（合规/硬件段瀑布）  
3. **按可交付物分方法**（不同组件不同方法）  
4. **按阶段切换**（前期探索敏捷，后期固化预测）  

## 四、选方法三要素

| 维度 | 看什么 |
|------|--------|
| 产品/服务/结果 | 创新度、需求清晰度、法规/安全约束、可增量交付否 |
| 项目 | 不确定性、复杂度、干系人参与频率、风险 |
| 组织 | 文化、结构、团队敏捷成熟度、治理要求 |

**口诀：产品能不能切块、项目乱不乱、组织允不允许——三者一起裁剪。**

## 五、与绩效域互动

- 开发方法影响规划详尽度、度量方式、团队协作与变更路径  
- 同一项目生命周期内**可以**存在多种节奏/方法（裁剪合法）  

## 六、易错对照

| 题干信号 | 选这 | 别选那 |
|----------|------|--------|
| 需求模糊、需快速验证 | 适应型/增量交付 | 强行完整瀑布详规 |
| 强监管、变更代价极高 | 预测或混合中的预测段 | 无视合规乱迭代 |
| 「一直用瀑布所以转型失败」 | 裁剪+试点+培训 | 全盘一天切敏捷 |
| 客户展会现场再定细节 | 混合/滚动规划 | 现在锁死全部设计 |
