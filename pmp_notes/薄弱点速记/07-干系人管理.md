## 先搞懂（58 题 · 近期 13）

干系人管理的底层假设：你不了解这个人，就无法管理他。文件是记忆，不是了解。

### 1. 为什么新来的人要先见面

登记册、PMIS 只能记下你已经知道的事。新干系人刚出现时，你还不知道他要什么、怕什么、权力有多大。先填表等于编造。  
正确顺序：会面 / 沟通 → 弄清期望 → 再更新登记册和参与计划。「先人后工具」停在第一下，不是永远不更新工具。

你的 #22 也是同一逻辑：启动阶段范围还很粗，**必须先识别相关方**，不是去批准项目管理计划（那是规划阶段的事）。

### 2. 抵制不是靠权力压下去的

人反对，通常有他在乎的损失。强制推进、群发邮件，会让反对变成对抗。先面对面问顾虑，才能改参与策略。  
沟通失败（报告发了对方说没收到）同理：加频率还是同一种无效方式。先做沟通需求分析——他到底要什么渠道、什么频率。

### 3. 权力利益方格是「投入多少精力」

高权力 + 高利益：他能让项目死，也最在乎结果 → 密切管理。  
高权力 + 低利益：能让你死但不天天盯着 → 让他满意就好，不必每天汇报（过度管理会惹烦）。  
低权力 + 高利益：要知情，否则小事变舆论。  
低权力 + 低利益：盯着就行。

关键人来不了会：补一份纪要是在用低效方式打发高影响的人。应改时间、请代理人，或开虚拟会，保证他真正参与决策。

## 三、权力/利益方格

| 权力 \ 利益 | 高利益 | 低利益 |
|-------------|--------|--------|
| **高权力** | ⭐ **密切管理** | **令其满意** |
| **低权力** | **随时告知** | **监督** |

**口诀**：**高权高利密切管，高权低利令满意，低权高利随时告，低权低利监督**

## 四、新干系人出现（超高频）

```
新干系人出现
  ↓
① 先会面/沟通，了解需求和期望
  ↓
② 再更新干系人登记册 / 参与计划
```

**口诀**：**先人后工具** — 不要先更新系统/登记册

---

## 五、干系人抵制

| 步骤 | 动作 |
|------|------|
| 1 | **沟通**了解顾虑（面对面） |
| 2 | 调整参与策略 |
| 3 | 更新登记册 |

❌ 不要：强制推进、忽视、只发邮件

---

## 六、与沟通管理的关系

- 沟通渠道数 = **n(n−1)/2**
- 沟通方法：**交互式 > 推式 > 拉式**
- 干系人题默认选**面对面/交互式**

---

## 七、高频考点

1. 权力/利益方格四象限策略
2. 新干系人 → 先沟通再更新登记册
3. 干系人识别是**持续过程**
4. 相关方抵制 → 沟通了解顾虑
5. 不要忽略低权力但高影响的干系人

---

## 八、易错陷阱

| ❌ 错 | ✅ 对 |
|------|------|
| 新干系人先更新 PMIS | 先会面沟通 |
| 只关注高权力 | 低权力高利益也要告知 |
| 抵制就强制 | 先沟通了解 |
| 中期才识别干系人 | 启动就开始，持续识别 |
| 发邮件解决复杂问题 | 交互式沟通 |
| 每周发报告对方仍说没收到 | 先做沟通需求分析（方式/频率） |
| 高管与外部干系人决策打架 | 明确决策机制，不要各说各话 |
| 有人不能参会就事后补纪要 | 事前改时间/找替代者/虚拟会议优先 |
