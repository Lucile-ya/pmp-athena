## 三、挣值 EVM（必背）

### 四个基础量

| 缩写 | 含义 |
|------|------|
| **PV** | 计划价值 — 按计划应完成多少 |
| **EV** | 挣值 — 实际完成了多少（按预算价）⭐ 先算它 |
| **AC** | 实际成本 — 实际花了多少 |
| **BAC** | 完工预算 — 总预算 |

### 核心公式

| 指标 | 公式 | >0 / >1 | <0 / <1 |
|------|------|---------|---------|
| **CV** | EV − AC | 节约 | 超支 |
| **SV** | EV − PV | 提前 | 落后 |
| **CPI** | EV / AC | 节约 | 超支 |
| **SPI** | EV / PV | 提前 | 落后 |
| **TCPI** | (BAC−EV)/(BAC−AC) | 需更高效 | 还有空间 |

### EAC 完工估算

| 情景 | 公式 |
|------|------|
| 按当前效率继续 | EAC = AC + (BAC−EV)/CPI |
| 剩余按预算做 | EAC = AC + (BAC−EV) |
| 重新估算 | EAC = AC + 新自下而上估算 |

**口诀**：
- **减法看偏差（CV/SV），除法看指数（CPI/SPI）**
- **EV 比 PV 大就超前，EV 比 AC 大就省钱**
- **CPI<1 超支，SPI<1 落后**

## 四、储备分析（最高频易错）

| | 应急储备 | 管理储备 |
|--|----------|----------|
| 针对 | **已知**风险 | **未知**风险 |
| 谁控制 | 项目经理 | 发起人/管理层 |
| 在成本基准内？ | ✅ **包含** | ❌ **不包含** |
| 使用 | PM 可直接用 | **需变更基准** |

**成本基准 = 工作包成本 + 应急储备**（不含管理储备）

**口诀**：**应急在基准，管理要变更**

## 八、做题决策链

```
给数字 → 第一步算 EV
  ├─ 问成本 → CV、CPI
  ├─ 问进度 → SV、SPI
  ├─ 问能否按预算完工 → TCPI vs 1
  └─ 问最终花多少 → EAC
储备题 → 已知=应急（在基准），未知=管理（变更基准）
```
