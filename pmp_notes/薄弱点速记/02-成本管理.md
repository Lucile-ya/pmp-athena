## 项目财务管理（第10讲 · 2026-10-16）

先背这张，再做财务错题。不要换题库把同一章再刷一遍。

### 六个词

- **生命周期成本**：建设成本 + 交给客户之后的运行成本。
- **沉没成本**：已经花掉、收不回。决定项目还做不做时，不算它。
- **机会成本**：选了这个、放弃另一个所失去的收益。
- **收益递减**：人加一倍，工期不会缩成一半。
- **折旧**：资产随时间掉值。直线折旧对税更不利。
- **价值工程**：用在新产品上，降成本、提质量。老产品用的是价值分析。

### 成本从哪来

资源、采购、风险、质量。质量成本三块：预防、评估、失败（内部/外部）。

### 两笔储备

- **应急储备**：已知风险。算进成本基准，项目经理可以动。
- **管理储备**：未知风险。不在成本基准里。要用先走变更。
- **项目预算** = 成本基准 + 管理储备。基准批准后，只能走变更来改。

### 估算

越到后期越准。粗略量级大约 −25%～+75%，确定性大约 −5%～+10%。要最有把握，用自下而上，不用类比。

### 挣值（先认这五个）

- CV = EV − AC。大于 0 省钱，小于 0 超支。
- SV = EV − PV。大于 0 提前，小于 0 落后。
- CPI = EV / AC。小于 1 超支。
- SPI = EV / PV。小于 1 落后。
- TCPI 大于 1：剩下的钱要花得比原来更省，很难完成。

CV 为负、SV 为正：多半在赶工，拿钱换时间。CV 为正、SV 为负：多半还没开工，看着省钱、进度落后。

讲义把完工估算（EAC）标成参考。这五个先认熟。

## 先搞懂（32 题 · 近期只有 4 道，不必当主战场）






### 自动钉死（更新于 2026-11-19）

> 来自错题本高频口诀，跟「易错陷阱 / 背这句」同源，每天先扫这 5 条。

1. **预算削减先查融资/资金措施** — 别直接砍范围
2. **储备够不够看过往绩效预测** — 别只报还剩多少钱
3. **成本控制用项目管理信息系统** — 别只口头压预算
4. **材料短缺风险要多元化供应** — 别干等一家供应商
5. **迭代功能按优先级做成本分析** — 别平均撒资源

### 1. 余钱不是用来「再做好一点」的（你的 #84）

项目答应交付的东西已经交付，进入收尾。账上还剩时间和钱，有人想加功能，你选了「拿去再做一轮质量检查」。

质量检查听起来正确，但**关闭标准已经满足**。再加功能、再加一轮没要求的 QC，都是范围外的工作（镀金）。剩下的钱和时间属于组织，确认关闭后释放掉，让别的项目用。

只有走变更并被批准，才能加。拥护者「希望」≠ 批准。

### 2. 为什么不能只看「花了多少钱」

PV = 计划此刻该完成的价值。  
AC = 实际已经掏出去的现金。  
**EV = 按预算计价，你真正干完了多少活。**

花了预算的 80%，可能只干完 50%——那是超支，不是「快做完了」。  
所以题目给数字时，先在脑子里算出 EV，再用 EV 减 AC 看成本、用 EV 减 PV 看进度。CPI、SPI 只是这两个比较的除法版：小于 1 就是落后/超支。

### 3. 两口袋钱，别混

**应急储备**：已知风险（零件可能涨价）。放进成本基准，PM 可以动。  
**管理储备**：未知的未知（没人想到的事）。不在基准里，要用等于改基准，得走变更，通常是发起人批。

题干说「已知可能波动」→ 储备分析 / 应急。说「没想到的事要动用」→ 管理储备 + 变更。

### 4. 估算方法看你手里有什么

类比 = 有类似项目，快但不准。  
参数 = 有公式和历史数据（单价 × 数量）。  
三点 = 有乐观/最可能/悲观，用来对付不确定性。  
自下而上 = 把工作包逐个估再加总，最准也最慢。

你的 #45：全新项目、**没有任何可参考数据** → 类比和三点都没输入，只能自下而上。不是「不确定就三点」。

### 5. 控制成本在管什么（今天又错）

控制成本 ≠ 再估一遍、≠ 建基准。核心是：**盯住会改成本基准的因素，确保变更有益**，再用绩效信息纠偏。  
题干问「成本控制的重点」→ 选「影响基准变化的因素 / 变更有益」，别选估算、汇总、建立基准。

### 6. 资金到位受限 ≠ 先改成本基准

客户资金到账有时间限制（资金限制平衡）→ 先**调整进度**，让支出节奏匹配资金到位，不是先动成本基准或狂提变更单。

### 7. 图里只有 AC + PV，没法判预算健不健康

CV / CPI 都要 **EV**。题图只有实际成本(AC)和计划(PV)、缺完成工作价值(EV) → 选「没有完成工作的信息，无法得知」。别瞎猜「预算水平有问题」。

### 8. 超支风险尽量甩给卖方 → FFP

固定总价（FFP）把成本超支风险压给卖方。  
FPEPA 只调物价；CPIF / CPFF 是成本补偿，买方风险更大。问「尽可能转移成本超支风险」→ **FFP**。

### 9. 客户拒掉预算内必要外聘

计划里写了要外聘、预算也够，客户嫌贵拒绝 → **先评估不做外聘的后果，再当面解释**。别偷偷调别的项目资源硬顶，也别不评估就直接雇。

### 10. 提前完工能降成本，但是机会

发现提前交付能降成本、客户又盯下一个里程碑 → **走变更管理计划，跟客户谈**。别直接加人赶工，也别当成镀金乱加功能。

### 11. 你最糊的几处（按错题反推）

**① 三点估算 ≠ 储备分析 ≠「应急预算」选项**  
三点 = 乐观/最可能/悲观，用来**估一个数**。  
价格会晃、已知风险要留钱 → 选 **储备分析**（技术名）。  
选项里若出现「应急预算」——多半是干扰项；正确项通常写 **储备分析**。应急储备是口袋名，不是这道题的选项写法。  
你今天连错两遍：波动选三点 / 波动选「应急预算」。

**② 估算成本的工具 ≠ 制定预算的工具**  
自下而上、类比、参数、三点 → 多在**估算成本**。  
发起人要看「预算」、问编制预算用啥 → 优先想**储备分析**（把应急/管理储备放进预算结构）。别一看到「准」就选自下而上（你今天又选自下而上了）。

**③ 可能结果分布 → 蒙特卡洛**  
要的是「整个项目可能结果的概率分布」，不是关键路径、不是资源平衡。蒙特卡洛用很多组成本和工期抽样，画出整体分布。

**④ 控制账户 = 范围 + 预算 + 进度的整合点**  
别拆开各管各的。考「在哪把范围/预算/进度对齐盯控」→ **控制账户（CA）**。

**⑤ 发起人嫌预算贵，有历史数据时**  
不是换更「准」的估算法糊弄人，而是**用类似项目历史数据证明合理性**。

**⑥ 只给了 EV、PV（没问成本）**  
SV=EV−PV<0 → 进度落后 → **进度压缩**（赶工/快速跟进），别先去乱动成本基准。

**⑦ 压力下要改质量/成本基准**  
先做**质量成本 + 可持续权衡**分析，再走变更。别「客户催了就立刻改基准」。

公式表在下面第三节，懂了这些再去扫。

## 三、挣值 EVM（必背）

### 四个基础量

| 缩写 | 含义 |
|------|------|
| **PV** | 计划价值 — 按计划应完成多少 |
| **EV** | 挣值 — 实际完成了多少（按预算价）⭐ 先算它 |
| **AC** | 实际成本 — 实际花了多少 |
| **BAC** | 完工预算 — 总预算 |

### 核心公式

| 指标 | 公式 | >0 / >1 | <0 / <1 |
|------|------|---------|---------|
| **CV** | EV − AC | 节约 | 超支 |
| **SV** | EV − PV | 提前 | 落后 |
| **CPI** | EV / AC | 节约 | 超支 |
| **SPI** | EV / PV | 提前 | 落后 |
| **TCPI** | (BAC−EV)/(BAC−AC) | 需更高效 | 还有空间 |

### EAC 完工估算

| 情景 | 公式 |
|------|------|
| 按当前效率继续 | EAC = AC + (BAC−EV)/CPI |
| 剩余按预算做 | EAC = AC + (BAC−EV) |
| 重新估算 | EAC = AC + 新自下而上估算 |

**口诀**：
- **减法看偏差（CV/SV），除法看指数（CPI/SPI）**
- **EV 比 PV 大就超前，EV 比 AC 大就省钱**
- **CPI<1 超支，SPI<1 落后**

## 四、储备分析（最高频易错）

| | 应急储备 | 管理储备 |
|--|----------|----------|
| 针对 | **已知**风险 | **未知**风险 |
| 谁控制 | 项目经理 | 发起人/管理层 |
| 在成本基准内？ | ✅ **包含** | ❌ **不包含** |
| 使用 | PM 可直接用 | **需变更基准** |

**成本基准 = 工作包成本 + 应急储备**（不含管理储备）

**口诀**：**应急在基准，管理要变更**

**再钉一句**：登记册里**已经写明的风险**（大雨毁混凝土等）→ 动**应急储备**。  
「预算储备」太笼统；管理储备留给未知的未知。

## 五、估算方法

| 方法 | 特点 | 何时用 |
|------|------|--------|
| 类比 | 快、粗 | 早期 |
| 参数 | 历史公式 | 有数据 |
| 自下而上 | 最准、最费时 | 详细规划；**无历史数据时也靠它** |
| 三点 | (O+4M+P)/6 | 估数值、不确定性大 |
| 蒙特卡洛 | 大量抽样出**结果分布** | 问「可能结果分布/概率」 |
| 储备分析 | 留应急/管理储备 | **制定预算**；价格波动留钱 |

**别混**：三点是估数；储备是留钱；蒙特卡洛是画分布。

```
给数字 → 第一步算 EV
  ├─ 问成本 → CV、CPI
  ├─ 问进度 → SV、SPI
  ├─ 问能否按预算完工 → TCPI vs 1
  └─ 问最终花多少 → EAC（看偏差是否持续）

图里只有 AC + PV、问预算有没有问题？
  └─ 缺 EV → 无法得知（别猜预算水平）

问「成本控制重点」？
  └─ 管影响成本基准的因素 + 变更有益（别选估算/建基准）

资金到位有时间限制？
  └─ 调进度做资金限制平衡（别先改成本基准）

储备 / 不确定性？
  ├─ 已知风险 / 价格波动 → 储备分析 / 应急储备（在基准，PM 可用）
  ├─ 未知风险 / 基准外新组件 → 管理储备 + 变更基准
  └─ 问「储备够不够」→ 用过往绩效预测 / EAC，别只报余额

合同：尽量把成本超支风险转给卖方？
  └─ FFP（别选 FPEPA / CPIF / CPFF）

客户拒绝预算内必要外聘？
  └─ 评估后果 → 当面解释（别偷偷内部顶）

发现提前完工能降成本（机会）？
```
