## 先搞懂（32 题 · 近期只有 4 道，不必当主战场）

### 1. 余钱不是用来「再做好一点」的（你的 #84）

项目答应交付的东西已经交付，进入收尾。账上还剩时间和钱，有人想加功能，你选了「拿去再做一轮质量检查」。

质量检查听起来正确，但**关闭标准已经满足**。再加功能、再加一轮没要求的 QC，都是范围外的工作（镀金）。剩下的钱和时间属于组织，确认关闭后释放掉，让别的项目用。

只有走变更并被批准，才能加。拥护者「希望」≠ 批准。

### 2. 为什么不能只看「花了多少钱」

PV = 计划此刻该完成的价值。  
AC = 实际已经掏出去的现金。  
**EV = 按预算计价，你真正干完了多少活。**

花了预算的 80%，可能只干完 50%——那是超支，不是「快做完了」。  
所以题目给数字时，先在脑子里算出 EV，再用 EV 减 AC 看成本、用 EV 减 PV 看进度。CPI、SPI 只是这两个比较的除法版：小于 1 就是落后/超支。

### 3. 两口袋钱，别混

**应急储备**：已知风险（零件可能涨价）。放进成本基准，PM 可以动。  
**管理储备**：未知的未知（没人想到的事）。不在基准里，要用等于改基准，得走变更，通常是发起人批。

题干说「已知可能波动」→ 储备分析 / 应急。说「没想到的事要动用」→ 管理储备 + 变更。

### 4. 估算方法看你手里有什么

类比 = 有类似项目，快但不准。  
参数 = 有公式和历史数据（单价 × 数量）。  
三点 = 有乐观/最可能/悲观，用来对付不确定性。  
自下而上 = 把工作包逐个估再加总，最准也最慢。

你的 #45：全新项目、**没有任何可参考数据** → 类比和三点都没输入，只能自下而上。不是「不确定就三点」。

公式表在下面第三节，懂了这四件事再去扫。

## 三、挣值 EVM（必背）

### 四个基础量

| 缩写 | 含义 |
|------|------|
| **PV** | 计划价值 — 按计划应完成多少 |
| **EV** | 挣值 — 实际完成了多少（按预算价）⭐ 先算它 |
| **AC** | 实际成本 — 实际花了多少 |
| **BAC** | 完工预算 — 总预算 |

### 核心公式

| 指标 | 公式 | >0 / >1 | <0 / <1 |
|------|------|---------|---------|
| **CV** | EV − AC | 节约 | 超支 |
| **SV** | EV − PV | 提前 | 落后 |
| **CPI** | EV / AC | 节约 | 超支 |
| **SPI** | EV / PV | 提前 | 落后 |
| **TCPI** | (BAC−EV)/(BAC−AC) | 需更高效 | 还有空间 |

### EAC 完工估算

| 情景 | 公式 |
|------|------|
| 按当前效率继续 | EAC = AC + (BAC−EV)/CPI |
| 剩余按预算做 | EAC = AC + (BAC−EV) |
| 重新估算 | EAC = AC + 新自下而上估算 |

**口诀**：
- **减法看偏差（CV/SV），除法看指数（CPI/SPI）**
- **EV 比 PV 大就超前，EV 比 AC 大就省钱**
- **CPI<1 超支，SPI<1 落后**

## 四、储备分析（最高频易错）

| | 应急储备 | 管理储备 |
|--|----------|----------|
| 针对 | **已知**风险 | **未知**风险 |
| 谁控制 | 项目经理 | 发起人/管理层 |
| 在成本基准内？ | ✅ **包含** | ❌ **不包含** |
| 使用 | PM 可直接用 | **需变更基准** |

**成本基准 = 工作包成本 + 应急储备**（不含管理储备）

**口诀**：**应急在基准，管理要变更**

## 七、易错陷阱

| ❌ 错 | ✅ 对 |
|------|------|
| 花了 80% 预算 = 完成 80% | 看 EV 完成了多少 |
| 管理储备随便用 | 用管理储备 = 变更基准 |
| TCPI 分母用 BAC | 分母是 (BAC−AC) |
| 问进度却算 CV | SV/SPI 看进度 |
| 中途意外超支就瞒客户 | 透明沟通，让客户做成本-进度决策 |
| 几小时内要估算 | 粗略数量级/类比，别硬上自下而上 |
| 发起人质疑预算且有历史数据 | 用历史数据证明合理性，不是换估算法 |

## 八、做题决策链

```
给数字 → 第一步算 EV
  ├─ 问成本 → CV、CPI
  ├─ 问进度 → SV、SPI
  ├─ 问能否按预算完工 → TCPI vs 1
  └─ 问最终花多少 → EAC
储备题 → 已知=应急（在基准），未知=管理（变更基准）
时间极短要估算 → 类比/粗略数量级
意外超支 → 先透明沟通客户，再谈方案
已满足关闭标准 + 还有余钱 → 释放资源，不镀金（#84）
```
