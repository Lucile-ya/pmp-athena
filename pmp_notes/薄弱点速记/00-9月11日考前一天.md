### 1. 流水线 + 三道顽疾（20 分钟）

打开：[00-考前攻错决策卡](./00-考前攻错决策卡.md) **第一、二节**

出门前必须能说清这三句：

| # | 题在干什么 | 你当时容易选 | 正确停在哪 |
|:-:|------------|--------------|------------|
| **#83** | 数据已经丢了 | 开经验教训会 | 已发生 → 先跟团队找根因 |
| **#84** | 关闭标准已满足，还有余钱 | 再加一轮 QC / 加功能 | 释放资源，不镀金 |
| **#87** | 供应商交不了货 | 先改 Backlog / 换商 | 下一步先审采购协议 |

每道题只问一句：

> 这件事已经发生了吗？现在流水线该停在哪一格？

First / 首先 → 停在「搞清楚状况」。  
Next / 下一步 → 只往下走一格。  
Best / 最恰当 → 可以选完整路径，但不能越权、不能镀金。

### 2. 这题卡在哪一块（15 分钟）

打开：[00-三领域对比速记卡](./00-三领域对比速记卡.md)

做题前用 30 秒判断，不要四个领域一起想：

| 卡住的是 | 第一步常常是 |
|----------|----------------|
| **资源**（冲突、抢人、障碍） | 见面谈 / 协商 / 清障碍，不先升级 |
| **整合**（章程、变更、关闭） | 先评估影响；关了就释放资源 |
| **敏捷**（谁决定做什么） | PO 定优先级，团队定怎么做，SM 清路 |
| **干系人**（新面孔、抵制） | 先沟通了解，再更新登记册 |

题干同时出现好几类词，看**这一句真正卡住的问题**。  
例：敏捷项目 + 供应商交不了货 → 卡住的是合同，不是 Backlog（还是 #87）。

### 3. 公式只过这一张纸（10 分钟）

不必打开成本/质量全文。扫决策卡第四节，记住：

```
先算 EV（干完了多少活，按预算计价）
  问成本 → CV = EV−AC，CPI = EV/AC    <1 超支
  问进度 → SV = EV−PV，SPI = EV/PV    <1 落后

应急储备 = 已知风险，在基准里，PM 能用
管理储备 = 未知未知，不在基准，要用 = 变更基准

QA / 质量审计 = 过程合不合规
QC / 控制质量 = 交付物达不达标

问题 = 已经发生（问题日志）
风险 = 还没发生（风险登记册）
```

- [ ] EV 会先算
- [ ] 应急 / 管理不会混
