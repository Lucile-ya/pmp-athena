# 🔴 第一篇：商业环境

> **总口诀**：**先论证价值，再谈怎么干**

## 1. 概念定位

**商业环境** = 确保项目**对齐组织战略**，持续**创造并兑现商业价值**。

| 维度 | 含义 |
|------|------|
| 战略对齐 | 项目必须服务组织战略目标 |
| 价值论证 | 回答「为什么要做」 |
| 利益实现 | 收益何时、如何衡量 |
| 外部环境 | 法规 / 市场 / 技术 / 经济变化 |
| 组织变革 | 项目改变工作方式，要管理抵制 |

**PM 边界（必考）**：商业论证、效益计划由**发起人 / 商业分析师**主导；PM **只能建议，不能擅自修改**。

---

## 2. 过程链

| 过程 | 时机 | 核心输出 | 工具 |
|------|------|----------|------|
| 开发商业论证 | 启动前 | 商业论证、利益管理计划 | ROI / NPV / IRR |
| 评估变革准备度 | 启动 | 变革就绪评估 | ADKAR、Kotter |
| 管理利益实现 | 全周期 | 利益实现报告 | 利益跟踪矩阵 |

**过程口诀**：**论证在前，变革在启，利益跟全程**

---

## 3. 商业论证 & 效益管理

### 商业论证 (Business Case) — 为什么做？

四要素：**需分推评**

1. **需** — 商业需求（要解决什么问题）
2. **分** — 形势分析（现状、机会、威胁）
3. **推** — 推荐方案（为何选这个方案）
4. **评** — 成本效益分析（财务 + 非财务）

### 效益管理计划 — 值多少、何时见？

- KPI、ROI、NPV、IRR、投资回收期
- 收益可能在**项目结束后**才兑现
- **效益 ≠ 可交付成果**（交付物是产出，效益是价值）

### 项目选择标准（组合层面）

- ✅ 战略一致性 + 目标效益 + 测量指标
- ❌ CEO 主观拍板 / 计划文件好看 / 只满足部分干系人

---

## 4. 财务指标

| 指标 | 含义 | 判断 |
|------|------|------|
| **NPV** | 净现值 | **> 0** 才有投资价值 |
| **ROI** | 投资回报率 | 收益 / 投资 |
| **IRR** | 内部收益率 | 与组织基准收益率比较 |
| 回收期 | 多久回本 | 越短越好（辅助） |

**口诀**：**NPV 大于零才值得投**

---

## 5. 变革管理 · ADKAR

| 字母 | 英文 | 含义 |
|------|------|------|
| A | Awareness | 认知 — 为什么要变 |
| D | Desire | 意愿 — 愿意参与 |
| K | Knowledge | 知识 — 知道怎么做 |
| A | Ability | 能力 — 实际做到 |
| R | Reinforcement | 巩固 — 防止回退 |

**口诀**：**认意愿知能固**

变革四步：识别干系人 → 沟通好处 → 培训支持 → 管理抵制（**合作沟通，不强制**）

---

## 6. EEF vs OPA · 合规

| | EEF 事业环境因素 | OPA 组织过程资产 |
|--|------------------|------------------|
| 性质 | 约束，**改不了** | 工具，**拿来用** |
| 例子 | 法规、文化、市场 | 模板、经验教训、流程 |

- **合规** = 底线（内部政策 + 外部法规）
- **价值** = 目标（战略对齐 + 效益兑现）
- 合规达标 ≠ 项目成功

**外变处理（法规/市场/技术）**：**先评估影响 → 再决定是否变更**

---

## 7. 组织结构（商业环境常考）

| 类型 | PM 权限 vs 职能经理 |
|------|---------------------|
| 弱矩阵 | 职能经理 > PM |
| 平衡矩阵 | 大致相当 |
| **强矩阵** | **PM > 职能经理** |
| 项目型 | PM 最高 |

---

## 8. 商业环境 · 易错陷阱

| ❌ 错 | ✅ 对 |
|------|------|
| 商业论证写一次就完 | **持续审查**（环境变了要更新） |
| PM 直接改商业论证 | 只能**建议**，发起人或 BA 主导 |
| 合规达标 = 项目成功 | 还要看战略对齐和效益 |
| 法规变了立刻改计划 | **先评估影响** |
| 效益 = 可交付物 | 效益是价值，可能项目后才兑现 |
| 新 AI/新技术引入 | 先做**商业论证**分析价值 |

---

## 9. 商业环境 · 做题决策链

```
题干有 战略/价值/法规/变革/效益/NPV/ROI？
  ├─ 为什么做 → 商业论证（需分推评）
  ├─ 选哪个项目 → 战略对齐 + 效益指标 + 可测量
  ├─ 效益怎么量 → 效益管理计划 / KPI
  ├─ 抵制变革 → ADKAR + 沟通培训（不强制）
  ├─ 法规/市场/技术变了 → 先评估影响
  └─ NPV/ROI 计算 → NPV>0 有价值
问 First → 分析/评估/沟通，不选终局方案或升级
```

# 🔴 第二篇：成本管理

> **总口诀**：**挣值先算 EV，储备分应急和管理**

## 1. 概念定位

在**批准预算内**完成全部工作 = 规划 → 估算 → 预算 → 控制成本。

---

## 2. 四大过程

| 过程 | 过程组 | 核心输出 |
|------|--------|----------|
| 7.1 规划成本管理 | 规划 | 成本管理计划 |
| 7.2 估算成本 | 规划 | 成本估算 |
| 7.3 制定预算 | 规划 | **成本基准**、项目资金需求 |
| 7.4 控制成本 | 监控 | 工作绩效信息、成本预测 |

---

## 3. 挣值管理 EVM（必背）

### 四个基础量

| 缩写 | 全称 | 含义 |
|------|------|------|
| **PV** | Planned Value | 计划价值 — 按计划此时应完成多少 |
| **EV** | Earned Value | 挣值 — 实际完成了多少（按预算价）⭐ **先算它** |
| **AC** | Actual Cost | 实际成本 — 实际花了多少 |
| **BAC** | Budget at Completion | 完工预算 — 总预算 |

### 偏差 & 指数

| 指标 | 公式 | > 0 / > 1 | < 0 / < 1 |
|------|------|-----------|-----------|
| **CV** 成本偏差 | EV − AC | 节约 | **超支** |
| **SV** 进度偏差 | EV − PV | 提前 | **落后** |
| **CPI** 成本绩效 | EV / AC | 节约 | **超支** |
| **SPI** 进度绩效 | EV / PV | 提前 | **落后** |
| **TCPI** 完工绩效 | (BAC−EV)/(BAC−AC) | 需更高效 | 还有空间 |

**核心口诀**：
- **减法看偏差**（CV / SV）
- **除法看指数**（CPI / SPI）
- **EV 比 PV 大 → 超前；EV 比 AC 大 → 省钱**
- **CPI < 1 超支，SPI < 1 落后**

### EAC 完工估算（选公式看题干）

| 情景 | 公式 | 何时用 |
|------|------|--------|
| 按当前效率继续 | EAC = AC + (BAC−EV)/CPI | 偏差将持续 |
| 剩余按预算做 | EAC = AC + (BAC−EV) | 一次性偏差，后面正常 |
| 重新估算 | EAC = AC + 新自下而上估算 | 条件根本改变 |

### TCPI 判断

- TCPI **> 1** → 剩余工作需比原计划更高效才能按预算完工
- TCPI **< 1** → 还有余量

---

## 4. 储备分析（最高频易错 ⚠️）

| | 应急储备 | 管理储备 |
|--|----------|----------|
| 针对 | **已知**风险 | **未知**风险 |
| 谁批准使用 | **项目经理** | **发起人 / 管理层** |
| 在成本基准内？ | ✅ **包含** | ❌ **不包含** |
| 使用条件 | PM 可直接动用 | **必须变更基准** |

**成本基准 = 工作包成本 + 应急储备**（不含管理储备）

**口诀**：**应急在基准，管理要变更**

价格波动 / 市场不确定性 → **储备分析**（应急 + 管理）

---

## 5. 估算方法

| 方法 | 特点 | 何时用 |
|------|------|--------|
| 类比估算 | 快、粗 | 早期、信息少 |
| 参数估算 | 历史公式 | 有可靠数据 |
| **自下而上** | 最准、最费时 | 无历史数据的新项目 |
| 三点估算 | (O+4M+P)/6 | 不确定性大 |

**无历史数据** → 优先**自下而上**（不是专家判断/类比/三点）

---

## 6. 成本管理 · 易错陷阱

| ❌ 错 | ✅ 对 |
|------|------|
| 花了 80% 预算 = 完成 80% | 必须看 **EV** 完成了多少 |
| 管理储备随便用 | 用管理储备 = **变更成本基准** |
| TCPI 分母用 BAC | 分母是 **(BAC − AC)** |
| 问进度却算 CV | 进度用 **SV / SPI** |
| CPI<1 就说无法完成 | 看 TCPI 和 EAC，不一定绝对完不成 |
| 市场价格波动 | **储备分析**，不是直接加预算 |

---

## 7. 成本管理 · 做题决策链

```
给 PV/EV/AC 数字？
  第一步：确认/计算 EV
  ├─ 问成本表现 → CV、CPI（EV vs AC）
  ├─ 问进度表现 → SV、SPI（EV vs PV）
  ├─ 问能否按预算完工 → TCPI vs 1
  └─ 问最终花多少 → EAC（看偏差是否持续）

储备 / 不确定性题？
  ├─ 已知风险 → 应急储备（在基准内，PM 可用）
  └─ 未知风险 → 管理储备（基准外，需变更）

会议前 CEO 看预算？
  └─ 邀请外部客户前，先与内部 + CEO **审查成本管理计划**
```

# 🔴 第三篇：进度管理

> **总口诀**：**关键路径零浮动，赶工加钱并行险**

## 1. 概念定位

在资源约束下合理安排活动顺序和时间，**按时交付可交付成果**。

---

## 2. 六大过程

| 过程 | 过程组 | 核心输出 |
|------|--------|----------|
| 6.1 规划进度管理 | 规划 | 进度管理计划 |
| 6.2 定义活动 | 规划 | 活动清单、里程碑清单 |
| 6.3 排列活动顺序 | 规划 | 进度网络图 (PDM) |
| 6.4 估算活动持续时间 | 规划 | 持续时间估算 |
| 6.5 制定进度计划 | 规划 | **进度基准** |
| 6.6 控制进度 | 监控 | 工作绩效信息、进度预测 |

---

## 3. 关键路径 CPM

| 概念 | 定义 |
|------|------|
| **关键路径** | 网络图中**最长**路径 = 项目**最短**完成时间 |
| **总浮动时间 TF** | 活动可推迟而不影响项目总工期 |
| **关键路径活动** | 总浮动时间 = **0** |
| 多条关键路径 | ✅ 可能同时存在 |
| 非关键活动延迟 | 不超过浮动时间 → **不影响总工期** |

**口诀**：**最长路 = 最短工期，浮动为零在关键**

---

## 4. 进度压缩（必考 ⚠️）

| 技术 | 英文 | 原理 | 副作用 | 前提 |
|------|------|------|--------|------|
| **赶工** | Crashing | **加资源**（加班、加人） | **增加成本** | 资源驱动型活动 |
| **快速跟进** | Fast Tracking | **并行**原本串行的活动 | **增加风险**、可能返工 | 活动有可重叠空间 |

**选择口诀**：
- 有钱没时间 → **赶工**
- 敢担风险 + 有可并行活动 → **快速跟进**
- **无可重叠活动** → 不能快速跟进，考虑**资源优化/赶工**
- PMP 常考默认 → **赶工**优先

**资源优化（两个项目抢资源）** → 分析两项目，找**公共资源最有效使用**（不是直接请求更多资源）

---

## 5. 进度 vs 挣值

| 指标 | 公式 | 含义 |
|------|------|------|
| SV | EV − PV | 进度偏差 |
| SPI | EV / PV | 进度绩效指数 |

- SPI < 1 → 进度落后
- 进度落后 → **先根因分析**，再选赶工 / 快速跟进
- 进度问题 ≠ 直接全员加班

---

## 6. 估算 & 绩效

| 方法 | 准确度 | 阶段 |
|------|--------|------|
| 类比 | 低 | 启动 / 早期 |
| 参数 | 中 | 规划 |
| 三点 (PERT) | 中高 | 不确定性大 |
| 自下而上 | 高 | 详细规划 |

**产品改造 / 营销** → 需要**明确绩效指标**量化进度和结果

---

## 7. 进度管理 · 易错陷阱

| ❌ 错 | ✅ 对 |
|------|------|
| 快速跟进不加风险 | 并行**增加风险**，可能返工 |
| 只有一条关键路径 | **可能多条** |
| 缩短非关键活动能缩总工期 | **只有关键路径**才行 |
| 进度问题直接加班 | **先根因分析** |
| 时间表无可重叠活动还选快速跟进 | 选**资源优化**或**赶工** |
| 供应商沟通问题导致延迟 | **先分析供应商问题**，再定方案 |
| 交付紧 → 惩罚团队 | 优先**奖励**激励持续表现 |

---

## 8. 进度管理 · 做题决策链

```
问压缩工期？
  ├─ 有无活动可重叠？
  │    ├─ 无 → 资源优化 / 赶工（不加并行）
  │    └─ 有 → 快速跟进（接受风险）或赶工
  ├─ 加资源/加钱 → 赶工
  └─ 先确认是否在关键路径上（非关键缩短无效）

问浮动时间？
  └─ 关键路径活动 TF = 0

给网络图？
  └─ 找最长路径 = 关键路径

进度落后 + SPI<1？
  └─ 根因分析 → 赶工 / 快速跟进 / 范围协商
```
