## 先搞懂（26 题）

进度题核心就一件事：**关键路径上没有可以浪费的空闲。** 非关键路径有浮动，晚一点不一定拖总工期。

### 赶工 vs 快速跟进

赶工 = 同一件事加人/加班，**花钱**，顺序不变，风险主要是累和贵。  
快速跟进 = 本来先后做的事搭着做，**顺序变了**，返工风险上升。  
题干强调「必须压缩而且预算紧」才考虑并行；没说钱的约束就不要默认选快速跟进。

### 进度落后时不要直接全员加班

先问为什么落后（资源被抽走、依赖、范围暗增）。原因没找到就加班，是跳步骤。SPI < 1 只告诉你落后，不告诉你该赶工还是该改依赖。

公式和网络图规则在下面，先建立「关键路径零浮动、压缩要分清加钱还是搭接」。

## 三、关键路径 CPM

| 概念 | 定义 |
|------|------|
| **关键路径** | 最长路径 = 项目**最短**完成时间 |
| **总浮动时间** | 活动可推迟不影响总工期 |
| **关键路径活动** | 总浮动时间 = **0** |
| 多条关键路径 | ✅ 可能同时存在 |

**口诀**：**最长路 = 最短工期，浮动为零在关键**

## 四、进度压缩（必考）

| 技术 | 原理 | 副作用 | 适用 |
|------|------|--------|------|
| **赶工 Crashing** | **加资源** | **增加成本** | 资源驱动型活动 |
| **快速跟进 Fast Tracking** | **并行**活动 | **增加风险**、可能返工 | 有依赖时可并行 |

**选择口诀**：
- 有钱没时间 → **赶工**
- 敢担风险 → **快速跟进**
- 默认优先 → **赶工**（PMP 常考）

## 六、与挣值联动

- **SV = EV − PV**，**SPI = EV / PV**
- SPI < 1 → 进度落后
- 进度落后 + 要压缩 → 先分析根因，再选赶工/快速跟进

## 八、易错陷阱

| ❌ 错 | ✅ 对 |
|------|------|
| 快速跟进不加风险 | 并行增加风险 |
| 只有一条关键路径 | 可能多条 |
| 缩短非关键活动能缩总工期 | 只有关键路径才行 |
| 进度问题直接加班 | 先根因分析 |
| 要提前完工且不能加成本 | **快速跟进**（并行）；赶工要加钱 |
| 进度落后却在写文档 | 审查精简工件，抓实际交付 |
