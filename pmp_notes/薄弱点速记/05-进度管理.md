## 三、关键路径 CPM

| 概念 | 定义 |
|------|------|
| **关键路径** | 最长路径 = 项目**最短**完成时间 |
| **总浮动时间** | 活动可推迟不影响总工期 |
| **关键路径活动** | 总浮动时间 = **0** |
| 多条关键路径 | ✅ 可能同时存在 |

**口诀**：**最长路 = 最短工期，浮动为零在关键**

---

## 四、进度压缩（必考）

| 技术 | 原理 | 副作用 | 适用 |
|------|------|--------|------|
| **赶工 Crashing** | **加资源** | **增加成本** | 资源驱动型活动 |
| **快速跟进 Fast Tracking** | **并行**活动 | **增加风险**、可能返工 | 有依赖时可并行 |

**选择口诀**：
- 有钱没时间 → **赶工**
- 敢担风险 → **快速跟进**
- 默认优先 → **赶工**（PMP 常考）

## 六、与挣值联动

- **SV = EV − PV**，**SPI = EV / PV**
- SPI < 1 → 进度落后
- 进度落后 + 要压缩 → 先分析根因，再选赶工/快速跟进

---

## 七、高频考点

1. 识别关键路径、算浮动时间
2. 赶工 vs 快速跟进选哪个
3. 进度落后怎么压缩
4. 关键路径延迟 = 项目延迟
5. 先优化资源再调进度

---

## 八、易错陷阱

| ❌ 错 | ✅ 对 |
|------|------|
| 快速跟进不加风险 | 并行增加风险 |
| 只有一条关键路径 | 可能多条 |
| 缩短非关键活动能缩总工期 | 只有关键路径才行 |
| 进度问题直接加班 | 先根因分析 |

---

## 九、做题决策链

```
问压缩工期？
  ├─ 加资源/加钱 → 赶工
  ├─ 并行/重叠 → 快速跟进（风险↑）
  └─ 先确认是否在关键路径上
问浮动时间 → 关键路径 = 0
给网络图 → 找最长路径
```
