## 先搞懂（106 题 · 近期 50 · 今天主战场）

这块你不是不会「合作优于强迫」这句话，是**一紧张就想找个能立刻结束麻烦的选项**：升级、换人、把障碍踢给 PO、自己给方案。


### 自动钉死（更新于 2026-11-18）

> 来自错题本高频口诀，跟「易错陷阱 / 背这句」同源，每天先扫这 5 条。

1. **隐性知识靠对话回顾会外化** — 别只留手册当传承
2. **发起人拍板也要协作代表干系人** — 别只开小范围发起人会
3. **隐性知识靠协作导师面对面** — 别只发标准文档
4. **燃尽速度算剩余周数报干系人** — 别给虚假明确完工日
5. **阶段收尾要移交未决风险** — 别只勾标准核对单

### 1. 冲突为什么默认合作

项目还要一起做完。强迫能赢当下，但对方之后不配合，后面的题还会再考你。  
题干没写「安全事故 / 必须马上定 / 已经谈不拢」，就选面对面把问题摊开。回避是最差的，等于假装没发生。

### 2. 人不是你的，是职能经理的

矩阵组织里，组员的考核和编制在职能经理手里。你去指挥、去找 HR、去私下拦高管，都是越权。  
正确路径：先跟职能经理或另一个项目的 PM **谈怎么共享**。只有题干写明你没有权限、协商已无效，才上报发起人。

### 3. 障碍报上来，就是你（或 SM）的活

每日站会的第三问是「我碰到什么挡路」。仆人式领导的意思是：**路是你去清的**，不是让 PO 改优先级，也不是让团队自己忍。  
PO 决定做什么最有价值；挡路的依赖、权限、跨项目专家，是 SM/PM 的事。

### 4. 团队出问题，先让关系能说话

新负责人被资深工程师顶、成员不满但说不清、虚拟团队觉得被排除——共同点是**信任不够**。  
一对一审讯、改流程、PM 直接给技术方案，都跳过了「让人敢说话」。先开会谈对交付的影响，或做团队建设，信息才会出来。自组织团队内部矛盾，你要教练他们自己解决，而不是把答案塞给他们。

对照：[先搞懂再做题](./00-考前攻错决策卡.md)。过程表和 RACI 在下面，懂了这四条再扫。

## 三、RACI 矩阵

| 字母 | 含义 | 要点 |
|------|------|------|
| **R** Responsible | 执行 — 做事的人 | 可多个 |
| **A** Accountable | 负责 — 最终责任人 | **每活动仅 1 个 A** |
| **C** Consult | 咨询 — 双向沟通 | |
| **I** Inform | 告知 — 单向通知 | |

**口诀**：**一个 A，多个 R**

## 四、Tuckman 团队发展

| 阶段 | 特征 | PM 风格 |
|------|------|---------|
| 形成 Forming | 相互认识 | **指导型** |
| 震荡 Storming | **冲突出现** | **教练型** |
| 规范 Norming | 建立规则 | 参与型 |
| 成熟 Performing | 高效自治 | 授权型 |
| 解散 Adjourning | 释放资源 | 支持型 |

**口诀**：**形震规成散** — 不能跳过震荡期

---

## 五、冲突解决（最高频）

| 优先级 | 策略 | 何时 |
|:------:|------|------|
| 1 ⭐ | **合作/解决问题** | 默认首选，双赢 |
| 2 | 妥协 | 各让一步 |
| 3 | 缓和 | 强调共识 |
| 4 | 强迫 | **紧急**才用 |
| 5 | 回避 | 最差，暂时搁置 |

**口诀**：**合妥缓强避**（合作 > 妥协 > 缓和 > 强迫 > 回避）

## 八、易错陷阱

|------|------|
| 冲突首选强迫/升级 | 合作/解决问题 |

| 新负责人被质疑就私下劝 | 召集团队会，先集体面对交付影响 |
| 成员不满原因不明就一对一盘问 | 团队建设促信任，让人敢说 |
| 混合项目干系人障碍只授权团队 | PM 主动帮团队消除障碍 |
| 知识传承只交手册/文档 | **隐性知识**靠对话、回顾会、导师面对面 |
| 高优先级项目只开发起人会 | 发起人拍板 **+** 代表干系人协作对齐 |
| 阶段收尾只勾标准核对单 | 收尾必须移交**未决风险/外部依赖** |
| 资源计划上来就堆最佳实践 | 先摸清团队**知识水平**再编资源计划 |
| 冲突只当个人情绪 | 选能获**团队全力支持**的冲突策略 |

## 九、做题决策链

```
团队冲突？
  ├─ 默认 → 合作/解决问题（面对面）
  ├─ 要获团队全力支持的策略（别只当个人情绪）
  ├─ 紧急 → 强迫（最后手段）
  └─ 不要一上来升级/回避

知识传承 / 跨项目留人？
  └─ 隐性知识靠对话、回顾会、导师面对面（别只交手册）

高优先级 + 发起人参与？
  └─ 发起人拍板 + 代表干系人协作对齐（别只开小范围发起人会）

阶段收尾 / 移交？
  └─ 移交未决风险与外部依赖（别只勾核对单）

编资源计划前？
  └─ 先摸清团队知识水平（别上来堆最佳实践）

技能提升？
  └─ 导师辅导机会 > 单次培训
燃尽报完工？
  └─ 用速度算剩余周数区间，别给虚假明确日
资源被抢/矩阵 → 与职能经理协商
高管跨项目抢人且无权 → 上报发起人协作
站会障碍已发生 → SM/PM 亲自消除，不交 PO
内部冲突影响交付 → 团队会，先对交付影响
团队阶段题 → 形震规成散 + 对应领导风格
RACI 题 → 每活动一个 A
选项目评分 → 加权最高分，别被关键干系人偏好带偏
```
