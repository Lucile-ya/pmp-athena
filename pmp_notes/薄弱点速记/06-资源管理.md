## 先搞懂（106 题 · 近期 50 · 今天主战场）

这块你不是不会「合作优于强迫」这句话，是**一紧张就想找个能立刻结束麻烦的选项**：升级、换人、把障碍踢给 PO、自己给方案。

### 1. 冲突为什么默认合作

项目还要一起做完。强迫能赢当下，但对方之后不配合，后面的题还会再考你。  
题干没写「安全事故 / 必须马上定 / 已经谈不拢」，就选面对面把问题摊开。回避是最差的，等于假装没发生。

### 2. 人不是你的，是职能经理的

矩阵组织里，组员的考核和编制在职能经理手里。你去指挥、去找 HR、去私下拦高管，都是越权。  
正确路径：先跟职能经理或另一个项目的 PM **谈怎么共享**。只有题干写明你没有权限、协商已无效，才上报发起人。

### 3. 障碍报上来，就是你（或 SM）的活

每日站会的第三问是「我碰到什么挡路」。仆人式领导的意思是：**路是你去清的**，不是让 PO 改优先级，也不是让团队自己忍。  
PO 决定做什么最有价值；挡路的依赖、权限、跨项目专家，是 SM/PM 的事。

### 4. 团队出问题，先让关系能说话

新负责人被资深工程师顶、成员不满但说不清、虚拟团队觉得被排除——共同点是**信任不够**。  
一对一审讯、改流程、PM 直接给技术方案，都跳过了「让人敢说话」。先开会谈对交付的影响，或做团队建设，信息才会出来。自组织团队内部矛盾，你要教练他们自己解决，而不是把答案塞给他们。

对照：[先搞懂再做题](./00-考前攻错决策卡.md)。过程表和 RACI 在下面，懂了这四条再扫。

## 三、RACI 矩阵

| 字母 | 含义 | 要点 |
|------|------|------|
| **R** Responsible | 执行 — 做事的人 | 可多个 |
| **A** Accountable | 负责 — 最终责任人 | **每活动仅 1 个 A** |
| **C** Consult | 咨询 — 双向沟通 | |
| **I** Inform | 告知 — 单向通知 | |

**口诀**：**一个 A，多个 R**

## 四、Tuckman 团队发展

| 阶段 | 特征 | PM 风格 |
|------|------|---------|
| 形成 Forming | 相互认识 | **指导型** |
| 震荡 Storming | **冲突出现** | **教练型** |
| 规范 Norming | 建立规则 | 参与型 |
| 成熟 Performing | 高效自治 | 授权型 |
| 解散 Adjourning | 释放资源 | 支持型 |

**口诀**：**形震规成散** — 不能跳过震荡期

## 五、冲突解决（最高频）

| 优先级 | 策略 | 何时 |
|:------:|------|------|
| 1 ⭐ | **合作/解决问题** | 默认首选，双赢 |
| 2 | 妥协 | 各让一步 |
| 3 | 缓和 | 强调共识 |
| 4 | 强迫 | **紧急**才用 |
| 5 | 回避 | 最差，暂时搁置 |

**口诀**：**合妥缓强避**（合作 > 妥协 > 缓和 > 强迫 > 回避）

## 六、PM 领导力

| 概念 | 要点 |
|------|------|
| 仆人式领导 | 服务团队、清障碍（敏捷核心） |
| 情商 EQ | 自我认知/管理 + 社交认知/关系管理 |
| 虚拟团队 | 核心挑战 = **沟通** |
| 团队章程 | 团队共同制定规则（非 PM 独断） |

## 七、高频考点

1. 冲突解决选合作/解决问题
2. RACI 中 A 只能有一个
3. Tuckman 震荡期 PM 做什么（教练，不是强制）
4. 团队建设**贯穿全项目**
5. 矩阵型组织 → 与职能经理**协商**资源

## 八、易错陷阱

| ❌ 错 | ✅ 对 |
|------|------|
| 冲突首选强迫/升级 | 合作/解决问题 |
| 跳过震荡期 | 必经阶段 |
| PM 独断建团队章程 | 团队共同参与 |
| 资源冲突直接找高管 | 先谈判/协商 |
| 团队建设只在开始 | 贯穿全程 |
| 高管跨项目抢人就私下谈/找 HR | 上报发起人协作 |
| 站会障碍丢给 PO | SM/PM 仆人式领导，当场消除障碍 |
| 新负责人被质疑就私下劝 | 召集团队会，先集体面对交付影响 |
| 成员不满原因不明就一对一盘问 | 团队建设促信任，让人敢说 |
| 混合项目干系人障碍只授权团队 | PM 主动帮团队消除障碍 |

## 九、做题决策链

```
团队冲突？
  ├─ 默认 → 合作/解决问题（面对面）
  ├─ 紧急 → 强迫（最后手段）
  └─ 不要一上来升级/回避
资源被抢/矩阵组织 → 与职能经理协商
高管跨项目抢人且无权 → 上报发起人
站会障碍已发生 → SM/PM 亲自消除，不交 PO
内部冲突影响交付 → 团队会，先对交付影响
团队阶段题 → 形震规成散 + 对应领导风格
RACI 题 → 每活动一个 A
```
